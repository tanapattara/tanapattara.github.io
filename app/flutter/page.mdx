# Flutter

Flutter คือ open-source framework สำหรับสร้าง UI (User Interface) ที่พัฒนาโดย Google โดยใช้ภาษา Dart ในการเขียนโค้ด จุดเด่นของ Flutter คือสามารถสร้างแอปพลิเคชันที่ทำงานได้บนหลายแพลตฟอร์ม (cross-platform) ทั้ง Android, iOS, เว็บ, และเดสก์ท็อป จากฐานโค้ดเดียว ทำให้ประหยัดเวลาและทรัพยากรในการพัฒนา

## ประวัติของ Flutter

Flutter มีประวัติการพัฒนาที่น่าสนใจ เริ่มต้นจากโครงการภายในของ Google ที่ชื่อว่า "Sky" ในปี 2015 โดยมีเป้าหมายในการสร้าง framework ที่สามารถ render UI ได้อย่างรวดเร็วบนแพลตฟอร์ม Android

ต่อมาในปี 2017 Flutter ได้เปิดตัวอย่างเป็นทางการในชื่อ "Flutter alpha" และได้รับความสนใจจากนักพัฒนาอย่างรวดเร็ว เนื่องจากความสามารถในการสร้างแอปพลิเคชัน cross-platform และประสิทธิภาพที่สูง

Flutter ได้รับการพัฒนาและปรับปรุงอย่างต่อเนื่อง โดยมีการเปิดตัวเวอร์ชันใหม่ ๆ ที่เพิ่มความสามารถและเสถียรภาพมากขึ้น ในปี 2018 Flutter 1.0 ได้รับการเปิดตัวอย่างเป็นทางการ ซึ่งถือเป็นเวอร์ชันที่มีความเสถียรและพร้อมสำหรับการใช้งานในเชิงพาณิชย์

Flutter ยังคงได้รับความนิยมและเติบโตอย่างต่อเนื่อง โดยมีการนำไปใช้ในการพัฒนาแอปพลิเคชันที่หลากหลายทั้งขนาดเล็กและขนาดใหญ่ รวมถึงแอปพลิเคชันของ Google เอง เช่น Google Ads

**เหตุการณ์สำคัญในประวัติของ Flutter:**

- **2015:** เริ่มต้นโครงการ "Sky"
- **2017:** เปิดตัว Flutter alpha
- **2018:** เปิดตัว Flutter 1.0
- **2019:** เปิดตัว Flutter 1.12
- **2020:** เปิดตัว Flutter 1.20
- **2021:** เปิดตัว Flutter 2.0 (รองรับ Web, Windows, macOS, Linux)
- **2022:** เปิดตัว Flutter 3.0 (รองรับ foldable phones)
- **2023:** เปิดตัว Flutter 3.7
