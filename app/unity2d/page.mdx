# 2D Game Development

2D Game Development เป็นการเรียนรู้เกี่ยวกับกระบวนการสร้างเกมสองมิติ ตั้งแต่การออกแบบเกม การสร้างตัวละครและฉาก การเขียนโปรแกรมควบคุมการเล่นเกม ไปจนถึงการทดสอบและเผยแพร่เกม ผู้เรียนจะได้เรียนรู้หลักการพื้นฐานของการพัฒนาเกม เช่น การออกแบบเกมเพลย์ การสร้างกราฟิกสองมิติ การเขียนสคริปต์ และการใช้เครื่องมือพัฒนาเกมต่างๆ

ปัจจุบันมีเครื่องมือและเอนจิ้นสำหรับพัฒนาเกม 2D มากมายที่ช่วยให้การสร้างเกมเป็นเรื่องง่ายขึ้น ไม่ว่าจะเป็นผู้เริ่มต้นหรือมืออาชีพ ตัวอย่างเครื่องมือที่ได้รับความนิยม ได้แก่

- **Unity:** เอนจิ้นยอดนิยมที่รองรับทั้งการพัฒนาเกม 2D และ 3D มีเครื่องมือและฟีเจอร์หลากหลายที่ช่วยให้การสร้างเกมเป็นเรื่องง่าย

- **Unreal Engine:** อีกหนึ่งเอนจิ้นทรงพลังที่รองรับการพัฒนาเกม 2D และ 3D คุณภาพสูง เหมาะสำหรับโครงการขนาดใหญ่
- **GameMaker Studio 2:** เครื่องมือที่ออกแบบมาเพื่อการพัฒนาเกม 2D โดยเฉพาะ มีระบบลากวาง (Drag and Drop) ที่ใช้งานง่าย
- **Godot Engine:** เอนจิ้นแบบ Open Source ที่มีประสิทธิภาพสูง รองรับการพัฒนาเกม 2D และ 3D เหมาะสำหรับนักพัฒนาที่ต้องการความยืดหยุ่น

## **คำอธิบายรายวิชา**

การออกแบบเกม ประเภทของเกม 2 มิติ องค์ประกอบของเกม 2 มิติ กระบวนการในการพัฒนาเกม การนำเกมไปประยุกต์ใช้ในงานด้านต่างๆ และเครื่องมือต่างๆ ที่ใช้สำหรับการพัฒนาเกม การพัฒนาเกมเพื่อให้สามารถเชื่อมโยงผ่านระบบเครือข่าย การติตตั้งและการส่งออกไปยังอุปกรณ์ การฝึกปฏิบัติ
