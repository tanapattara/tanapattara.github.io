# Camera

ที่วัตถุ Main camera มีคุณสมบัติสำคัญ ในหน้าต่าง Inspector อยู่สองอย่าง

- Size ระบุขนาดของกล้อง เราสามารถกำหนดขนาดของกล้องเป็นตัวเลขได้
- Projection ในเกมส์สองมิติ เราจะใช้แบบ Orthographic ส่วนแบบ Perspective ใช้ในการทำงานแบบสามมิคิ
- ตำแหน่งของกล้อง จะต้องอยู่ด้านหน้าของฉากอื่น ๆ ดูได้จาก Position Z มีค่าเป็นลบ หรือดูได้จากหน้า Scene แล้วปรับเป็น 3D ก็จะทำให้เรามองเห็นตำแหน่งของกล้องเรา กล้องเราจะต้องอยู่ด้านบน หรือเหนือวัตถุอื่น ๆ เพื่อทำให้เราสามารถมองเห็นวัตถุอื่นได้
- ที่ Inspector → Camera → Culling Mask เราสามารถเลือกเลเยอร์ที่เราต้องการแสดงในกล้องได้  หากเราไม่เลือกเลเยอร์นั้น ก็จะไม่ปรากฎในกล้องของเรา
- Inspector → Camera → Clear Flags + Background เอาไปเลือกสี Background ของฉากหลังที่ไม่ใช่พื้นฉากของเกมได้ เราสามารถปรับให้เข้ากับฉากในเกมส์เพื่อให้ง่ายต่อการทำงาน เราจะได้ไม่ต้องเดิมฉากหลังขนาดใหญ่เข้าไปอีกที

## Follow Camera

เมื่อตัวละครของเราเดินไปในฉากที่มีขนาดใหญ่ เราจำเป็นที่ต้องกำหนดให้กล้องเคลื่อนที่ตามตัวละครของเรา การทำแบบนั้น เราต้องทำการติดตั้ง Package Manager ที่ชื่อว่า Cinemachine

เมื่อติดตั้งแล้วให้คลิ๊กขวาเพื่อสร้างวัตถุใหม่ Cinemachine → 2D Camera เราจะได้วัตถุที่ชื่อ Virtual Camera มาใหม่

ที่ Main Camera เดิม จะมีสัญญาลักษณ์สีแดง ที่ด้านขวาของชื่อ นั่นคือเมื่อเราสร้าง Cinemachine ขึ้นมา ตัว Main Camera ก็จะถูกผูกเข้ากับคอมโพแนนท์ที่ชื่อ CinemachineBrain

ที่ Virtual Camera ที่สร้างขึ้นมาใหม่ จะมี CinemachineVirtualCamera คอมโพแนนท์ที่หน้าต่าง Inspector ให้เราทำการเปลี่ยน Follow เป็น Player โดยการลากวัตถุ Player มาที่ช่อง Follow

ตอนนี้กล้องของเราจะมีการเคลื่อนที่ตามตัวละครของเราแล้ว

### Dead Zone

เป็นการกำหนดขอบเขตของกล้อง โดยจะกำหนดพื้นที่เล็ก ๆ รอบ ๆ ตัวละคร หากตัวละครเรายังอยู่ในพื้นที่นี้ กล้องก็จะไม่มีการเคลื่อนที่

ให้ทำการเลือก CinemachineVirtualCamera → Game Window Guides ก่อน เพื่อเปิดเส้นนำทาง โดยเราจะเห็นเป็นพื้นที่สีฟ้า รอบ ๆ ตัวละคร

ในตอนแรกจะมีเส้นสีฟ้าตัดที่ตัวละครของเราพอดี ให้ลองทำการปรับ Dead Zone Width และ Height เพื่อทำให้เกิดพื้นที่ขึ้นมา พื้นที่นั้นก็จะเป็นพื้นที่ Dead Zone
