# Install and Setup

## Tool

- Visual Studio Code
- Flutter Extension for Visual Studio Code
- Android Studio

## Installation

1.  ติดตั้งไฟล์จาก  Flutter ไปที่โฟลเดอร์ที่ต้องการ เช่น `c:/dev/`
2.  ตั้งค่า System Variable โดยการใส่ path ของ Flutter ที่เราติดตั้งเข้าไป จากข้อ 1 เราจะได้ `c:\dev\flutter\bin`
3. บันทึกและลองทดสอบโดยการพิมพ์คำสั่ง `flutter doctor` ที่ cmd หรือ terminal
