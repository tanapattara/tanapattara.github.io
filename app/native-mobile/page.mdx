# Native Mobile Application Programming with Flutter

รายวิชานี้ศึกษาการพัฒนาแอปพลิเคชันบนอุปกรณ์เคลื่อนที่ โดยใช้ **Flutter และภาษา Dart** เป็นเครื่องมือหลัก ผู้เรียนจะได้สร้าง UI ที่ปรับตามขนาดหน้าจอ จัดการ State เชื่อมต่อ REST API บันทึกข้อมูลในเครื่อง ขอ Permission ใช้ความสามารถของอุปกรณ์ ทดสอบ และเตรียมแอปสำหรับเผยแพร่

Flutter เป็น cross-platform UI toolkit ที่ใช้ codebase ร่วมกันบน Android และ iOS แต่ยังสามารถเรียก Native API ผ่าน Plugin หรือ Platform Channel ได้ จึงเหมาะสำหรับใช้เรียนทั้งแนวคิด Mobile Application และการสร้างผลิตภัณฑ์ที่ใช้งานจริง

## ผลลัพธ์การเรียนรู้

เมื่อเรียนครบ ผู้เรียนจะสามารถ:

- อธิบายข้อจำกัดของอุปกรณ์เคลื่อนที่และเลือกแนวทางออกแบบที่เหมาะสม
- เขียน Dart ที่ใช้ Null Safety, Future, Stream และ Object-Oriented Programming ได้
- สร้าง Flutter UI ที่ responsive, accessible และสอดคล้องกับ Material Design
- ออกแบบ Navigation, State Management และโครงสร้างแอปแบบแยก UI/Data layer
- เชื่อมต่อ API จัดการ JSON และบันทึกข้อมูลแบบ local/offline
- ใช้ Permission, Camera, Location และบริการของแพลตฟอร์มอย่างปลอดภัย
- เขียน Unit, Widget และ Integration Test และสร้าง Release Build ได้

> **พื้นฐานที่ควรมี:** การเขียนโปรแกรมเบื้องต้น ตัวแปร เงื่อนไข Loop Function Class และความเข้าใจ HTTP/JSON ระดับพื้นฐาน
