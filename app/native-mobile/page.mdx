# Native Mobile Application Programming

Native Mobile Application Programming คือ การพัฒนาแอปพลิเคชันสำหรับอุปกรณ์พกพา (เช่น สมาร์ทโฟน แท็บเล็ต) โดยใช้ภาษาโปรแกรมและเครื่องมือที่เฉพาะเจาะจงสำหรับระบบปฏิบัติการนั้นๆ เช่น 

- iOS:  ใช้ภาษา Objective-C หรือ Swift และพัฒนาด้วย Xcode
- Android: ใช้ภาษา Java หรือ Kotlin และพัฒนาด้วย Android Studio
- แอปพลิเคชันที่พัฒนาแบบ Native จะสามารถเข้าถึงฟังก์ชันต่างๆ ของอุปกรณ์ได้อย่างเต็มที่ เช่น กล้อง GPS เซ็นเซอร์ต่างๆ ทำให้แอปพลิเคชันมีประสิทธิภาพสูงและตอบสนองได้รวดเร็ว

**ข้อดี**ของ Native Mobile Application Programming:

- ประสิทธิภาพสูง: ทำงานได้รวดเร็วและเสถียร
- เข้าถึงฟังก์ชันของอุปกรณ์ได้เต็มที่:  ใช้ประโยชน์จากฮาร์ดแวร์และซอฟต์แวร์ของอุปกรณ์ได้อย่างเต็มที่
- User Experience ที่ดี:  ใช้งานง่ายและมี UI ที่สอดคล้องกับระบบปฏิบัติการ
- ความปลอดภัยสูง:  ควบคุมความปลอดภัยได้ดีกว่า

**ข้อเสีย**ของ Native Mobile Application Programming: 

- ค่าใช้จ่ายสูง:  ต้องพัฒนาแยกสำหรับแต่ละแพลตฟอร์ม
- ใช้เวลาพัฒนานาน:  ต้องเขียนโค้ดแยกสำหรับ iOS และ Android
- ต้องมีความเชี่ยวชาญเฉพาะด้าน:  ต้องมีความรู้ความเข้าใจในระบบปฏิบัติการนั้นๆ

ตัวอย่างแอปพลิเคชันที่พัฒนาแบบ Native: 

- เกมส์
- แอปพลิเคชันที่ต้องใช้ทรัพยากรเครื่องสูงๆ
- แอปพลิเคชันที่ต้องการความปลอดภัยสูง

Native Mobile Application Programming เหมาะสำหรับแอปพลิเคชันที่ต้องการประสิทธิภาพสูง ใช้งานฟังก์ชันของอุปกรณ์ได้เต็มที่ และมี User Experience ที่ดี  แต่ต้องแลกมาด้วยค่าใช้จ่ายและเวลาในการพัฒนาที่สูงกว่า

## คำอธิบายรายวิชา

สถาปัตยกรรมฮาร์ดแวร์ คุณลักษณะและข้อจํากัดของอุปกรณ์เคลื่อนที่ เครื่องมือและภาษาที่ใช้สําหรับพัฒนาโปรแกรมประยุกต์บนอุปกรณ์เคลื่อนที่ การพัฒนาโปรแกรมประยุกต์บนอุปกรณ์เคลื่อนที่โดยใช้ภาษาแม่ กระบวนการพัฒนาโปรแกรมประยุกต์บนอุปกรณ์เคลื่อนที่ การใช้หน่วยความจําและส่วนเก็บบันทึกข้อมูล การขออนุญาตและการเข้าถึงส่วนฮาร์ดแวร์ ส่วนติดต่อกับผู้ใช้ การสื่อสารเครือข่ายกับภายนอก การเชื่อมโยงกับระบบคอมพิวเตอร์ การทดสอบโปรแกรมประยุกต์บนอุปกรณ์เคลื่อนที่โดยใช้ระบบคอมพิวเตอร์ ประเด็นด้านความมั่นคง การฝึกปฏิบัติ
