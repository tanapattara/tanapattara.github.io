# Git and GitHub Overview

## Git

Git เป็นซอฟต์แวร์ระบบควบคุมเวอร์ชัน (Version Control System - VCS) ที่ได้รับความนิยมอย่างแพร่หลาย มีจุดเด่นคือสามารถติดตามและจัดการการเปลี่ยนแปลงในชุดไฟล์ได้อย่างมีประสิทธิภาพ โดยเฉพาะอย่างยิ่งกับโค้ดโปรแกรม ทำให้สามารถย้อนกลับไปดูประวัติการแก้ไข หรือแยกการทำงานเป็นสาขาต่างๆ ได้

## **หลักการทำงานของ Git:**

Git จะบันทึกการเปลี่ยนแปลงของไฟล์ในรูปแบบของ "snapshots" หรือภาพรวมของสถานะไฟล์ในแต่ละช่วงเวลา เมื่อมีการแก้ไขไฟล์ Git จะสร้าง snapshot ใหม่ขึ้นมา ทำให้สามารถเปรียบเทียบความแตกต่างระหว่าง snapshot ต่างๆ และย้อนกลับไปยังสถานะก่อนหน้าได้

## **ประโยชน์ของ Git:**

- **การทำงานเป็นทีม:** Git ช่วยให้หลายคนสามารถทำงานร่วมกันบนชุดไฟล์เดียวกันได้โดยไม่เกิดความขัดแย้ง
- **การติดตามประวัติ:** สามารถดูประวัติการแก้ไขไฟล์ทั้งหมดได้ ทำให้สามารถย้อนกลับไปยังเวอร์ชันก่อนหน้าได้หากเกิดข้อผิดพลาด
- **การสร้างสาขา (Branching):** สามารถสร้างสาขาใหม่เพื่อทดลองฟีเจอร์หรือแก้ไขข้อผิดพลาด โดยไม่กระทบกับโค้ดหลัก
- **การรวมโค้ด (Merging):** สามารถรวมการเปลี่ยนแปลงจากสาขาต่างๆ เข้าด้วยกันได้อย่างง่ายดาย

## GitHub

GitHub เป็นเว็บไซต์ที่ให้บริการพื้นที่เก็บข้อมูลและเครื่องมือต่างๆ สำหรับการทำงานร่วมกันบนโครงการซอฟต์แวร์ โดยใช้ Git เป็นระบบควบคุมเวอร์ชันหลัก

GitHub เป็นของบริษัท Microsoft โดย Microsoft ได้เข้าซื้อกิจการ GitHub เมื่อปี 2018

## **ความสัมพันธ์ระหว่าง Git และ GitHub:**

Git เป็นเครื่องมือที่ทำงานบนเครื่องคอมพิวเตอร์ของคุณ ใช้สำหรับติดตามและจัดการการเปลี่ยนแปลงในไฟล์โครงการ ในขณะที่ GitHub เป็นแพลตฟอร์มออนไลน์ที่ช่วยให้คุณสามารถ:

- **เก็บโค้ด:** อัปโหลดโค้ดจากเครื่องของคุณไปยัง GitHub เพื่อเก็บรักษาอย่างปลอดภัยและเข้าถึงได้จากทุกที่
- **ทำงานร่วมกัน:** ทำงานร่วมกับผู้อื่นบนโครงการเดียวกันได้อย่างง่ายดาย โดยสามารถดูการเปลี่ยนแปลงของกันและกัน รวมโค้ด และแก้ไขข้อขัดแย้งได้
- **แบ่งปันโค้ด:** แชร์โค้ดของคุณกับผู้อื่นได้ทั้งแบบส่วนตัวหรือสาธารณะ
- **ติดตามโครงการ:** ติดตามโครงการที่คุณสนใจ ดูการเปลี่ยนแปลง และมีส่วนร่วมในการพัฒนาได้
- **GitHub Issues:** ระบบติดตามและจัดการข้อผิดพลาดหรือปัญหาในโครงการ
- **GitHub Pull Requests:** ระบบสำหรับเสนอและตรวจสอบการเปลี่ยนแปลงโค้ดก่อนที่จะรวมเข้ากับโค้ดหลัก
- **GitHub Actions:** ระบบสำหรับการสร้างกระบวนการทำงานอัตโนมัติ เช่น การทดสอบและการปรับใช้โค้ด
- **GitHub Pages:** บริการสำหรับสร้างเว็บไซต์แบบคงที่จากโค้ดใน GitHub
