# ตัวแปร (Variables)

**ตัวแปรในภาษา C#**  ตัวแปรเปรียบเสมือนกล่องที่ใช้สำหรับเก็บข้อมูลต่างๆ ในโปรแกรมของเรา ข้อมูลเหล่านี้อาจจะเป็นตัวเลข ข้อความ หรือข้อมูลชนิดอื่นๆ

**ชนิดของตัวแปร**

ในภาษา C# มีตัวแปรหลายชนิด แต่ละชนิดถูกออกแบบมาเพื่อเก็บข้อมูลประเภทต่างๆ ดังนี้

- **int:** ใช้เก็บจำนวนเต็ม เช่น 10, 25, -5
- **double:** ใช้เก็บจำนวนทศนิยม เช่น 3.14, 2.718
- **char:** ใช้เก็บตัวอักษรเดี่ยว เช่น 'A', 'b', '?'
- **string:** ใช้เก็บข้อความ เช่น "Hello World", "TA-OOP"
- **bool:** ใช้เก็บค่าความจริง true หรือ false

**ตัวอย่างการใช้งาน**

```csharp
int age = 20;              // เก็บอายุเป็นจำนวนเต็ม
double weight = 65.5;      // เก็บน้ำหนักเป็นทศนิยม
char grade = 'A';          // เก็บเกรดเป็นตัวอักษร
string name = "John Doe";  // เก็บชื่อเป็นข้อความ
bool isStudent = true;     // เก็บสถานะนักศึกษาเป็น true 
```

**การประกาศตัวแปร**

การประกาศตัวแปรในภาษา C# ทำได้โดยระบุชนิดของตัวแปร ตามด้วยชื่อตัวแปร เช่น

```csharp
int numberOfStudents; 
```

**การกำหนดค่าให้ตัวแปร**

หลังจากประกาศตัวแปรแล้ว เราสามารถกำหนดค่าให้กับตัวแปรได้โดยใช้เครื่องหมายเท่ากับ (=) เช่น

```csharp
numberOfStudents = 30;
```

**การประกาศและกำหนดค่าในขั้นตอนเดียว**

เราสามารถประกาศตัวแปรและกำหนดค่าให้ในขั้นตอนเดียวกันได้ดังนี้

```csharp
string message = "Welcome to OOP class!";
```

**ข้อควรจำ**

- ชื่อตัวแปรต้องขึ้นต้นด้วยตัวอักษรหรือเครื่องหมาย _(underscore) เท่านั้น
- ชื่อตัวแปรไม่สามารถซ้ำกับคำสงวนในภาษา C# ได้
- ควรตั้งชื่อตัวแปรให้สื่อความหมาย

```csharp
// คำนวณพื้นที่ของสี่เหลี่ยมผืนผ้า
double width = 10.0;
double height = 5.0;
double area = width * height;
Console.WriteLine("Area of rectangle: " + area); // แสดงผลลัพธ์
```

ในตัวอย่างนี้ เราประกาศตัวแปร `width` และ `height` เพื่อเก็บความกว้างและความสูงของสี่เหลี่ยม  จากนั้นคำนวณพื้นที่และเก็บไว้ในตัวแปร `area` สุดท้ายแสดงผลลัพธ์ทางหน้าจอ
