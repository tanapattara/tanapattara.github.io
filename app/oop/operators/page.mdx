# ตัวดำเนินการ (Operators)

**Operand และ Operator** เป็นส่วนประกอบพื้นฐานที่ใช้ในการเขียนนิพจน์ (Expression) ในภาษา C#

**Operand** คือ ตัวแปร ค่าคงที่ หรือฟังก์ชันที่ถูกนำมาใช้ในการคำนวณหรือประมวลผล

**Operator** คือ สัญลักษณ์ที่ใช้ในการดำเนินการกับ Operand

**ตัวอย่าง**

ในนิพจน์ `a + b`

- `a` และ `b` คือ Operand
- `+` คือ Operator (บวก)

**ประเภทของ Operator**

ภาษา C# มี Operator หลายประเภท  เช่น

- **Operator ทางคณิตศาสตร์ (Arithmetic Operators)**: เช่น `+` (บวก),  (ลบ),  (คูณ), `/` (หาร), `%` (modulo)
- **Operator เปรียบเทียบ (Comparison Operators)**: เช่น `==` (เท่ากับ), `!=` (ไม่เท่ากับ), `>` (มากกว่า), `<` (น้อยกว่า), `>=` (มากกว่าหรือเท่ากับ), `<=` (น้อยกว่าหรือเท่ากับ)
- **Operator ตรรกะ (Logical Operators)**: เช่น `&&` (and), `||` (or), `!` (not)
- **Operator กำหนดค่า (Assignment Operators)**: เช่น `=` (กำหนดค่า), `+=` (บวกและกำหนดค่า), `=` (ลบและกำหนดค่า)
- **Operator บิต (Bitwise Operators)**: เช่น `&` (and), `|` (or), `^` (xor), `~` (not), `<<` (shift left), `>>` (shift right)

**ตัวอย่างการใช้งาน Operator**

```csharp
int x = 10;
int y = 5;

int sum = x + y;          // sum จะมีค่าเท่ากับ 15
bool isEqual = x == y;    // isEqual จะมีค่าเท่ากับ false
x += 5;                  // x จะมีค่าเท่ากับ 15 (x = x + 5)
```

**ลำดับความสำคัญของ Operator**

Operator แต่ละประเภทมีลำดับความสำคัญไม่เท่ากัน  เช่น  `*`  และ  `/`  มีลำดับความสำคัญสูงกว่า  `+`  และ  `-`

**การใช้เครื่องหมายวงเล็บ**

เราสามารถใช้เครื่องหมายวงเล็บ  `()`  เพื่อควบคุมลำดับการดำเนินการของ Operator ได้

**ตัวอย่าง**

```csharp
int result1 = 5 + 2 * 3;   // result1 จะมีค่าเท่ากับ 11
int result2 = (5 + 2) * 3; // result2 จะมีค่าเท่ากับ 21
```
