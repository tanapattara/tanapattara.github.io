# Object-Oriented Programming

วิชา Object-Oriented Programming (OOP) หรือ การเขียนโปรแกรมเชิงวัตถุ เป็นกระบวนทัศน์ในการพัฒนาซอฟต์แวร์ที่เน้นการจัดระเบียบโปรแกรมเป็นกลุ่มของวัตถุ (Object) ซึ่งเป็นตัวแทนของสิ่งต่าง ๆ ในโลกแห่งความเป็นจริง แต่ละวัตถุจะมีคุณสมบัติ (Attribute) และพฤติกรรม (Method) ที่เกี่ยวข้องกับสิ่งที่มันเป็นตัวแทนอยู่ OOP ช่วยให้โปรแกรมมีความยืดหยุ่น บำรุงรักษาได้ง่าย และนำกลับมาใช้ใหม่ได้ (Reusability)

ความสำคัญของวิชา Object-Oriented Programming:

1. **การจัดการความซับซ้อน:** OOP ช่วยจัดการความซับซ้อนของโปรแกรมขนาดใหญ่ได้ดี โดยการแบ่งโปรแกรมออกเป็นส่วนย่อย ๆ ที่เรียกว่าวัตถุ ทำให้เข้าใจและพัฒนาโปรแกรมได้ง่ายขึ้น
2. **การนำกลับมาใช้ใหม่:** วัตถุที่ถูกสร้างขึ้นสามารถนำกลับมาใช้ใหม่ในส่วนอื่น ๆ ของโปรแกรม หรือในโปรแกรมอื่น ๆ ได้ ช่วยลดเวลาและทรัพยากรในการพัฒนา
3. **ความยืดหยุ่น:** OOP ช่วยให้โปรแกรมมีความยืดหยุ่นในการเปลี่ยนแปลงและขยาย เนื่องจากการเปลี่ยนแปลงในวัตถุหนึ่งจะมีผลกระทบต่อส่วนอื่น ๆ ของโปรแกรมน้อย
4. **การบำรุงรักษา:** โปรแกรมที่เขียนด้วย OOP จะง่ายต่อการบำรุงรักษา เนื่องจากแต่ละวัตถุมีความเป็นอิสระต่อกัน การแก้ไขข้อผิดพลาดหรือปรับปรุงส่วนใดส่วนหนึ่งของโปรแกรมจะไม่ส่งผลกระทบต่อส่วนอื่น ๆ มากนัก
5. **มาตรฐานอุตสาหกรรม:** OOP เป็นกระบวนทัศน์ที่ใช้กันอย่างแพร่หลายในอุตสาหกรรมซอฟต์แวร์ การมีความรู้ความเข้าใจใน OOP จะเป็นประโยชน์อย่างมากในการทำงานในสายงานนี้

## คำอธิบายรายวิชา

 ****การออกแบบเชิงวัตถุ นามธรรมข้อมูล นามธรรมกระบวนการ นามธรรมชนิดข้อมูล คลาสและซับคลาส คอนสตรัคเตอร์ เดสตรัคเตอร์ การห่อหุ้มและการซ่อนข้อมูล การแบ่งแยกพฤติกรรมและการดำเนินงาน การส่งข้อความ องค์ประกอบอาร์เรย์ของวัตถุ การมองเห็นได้ โอเปอเรเตอร์โอเวอร์โหลดดิ้ง การสืบทอด โพลิมอร์ฟิซึม นามธรรมคลาส การเชื่อมต่อ คลาสแพคเกจ
