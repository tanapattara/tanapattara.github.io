# การทำซ้ำ (Loops)

การทำซ้ำ หรือ Looping เป็นหนึ่งในแนวคิดพื้นฐานที่สำคัญมากในการเขียนโปรแกรม  เปรียบเหมือนกับการที่เราต้องทำอะไรซ้ำๆ กันหลายครั้ง  เช่น  การล้างจาน  การซักผ้า  หรือการนับเลข  แทนที่เราจะเขียนโค้ดซ้ำๆ กัน  เราสามารถใช้ Looping เพื่อสั่งให้คอมพิวเตอร์ทำสิ่งเหล่านั้นซ้ำๆ ให้เราได้  ช่วยประหยัดเวลาและทำให้โค้ดกระชับขึ้น

**ประเภทของ Looping ใน C#**

ในภาษา C# มีโครงสร้างควบคุมการทำซ้ำ (Looping Structures) หลักๆ อยู่ 3 แบบ  ได้แก่

1. **`for` loop:** เหมาะสำหรับการทำซ้ำที่เรารู้จำนวนครั้งที่แน่นอน  เช่น  ต้องการวนลูป 10 ครั้ง  หรือวนลูปตามจำนวนข้อมูลใน Array
    
    ```csharp
    
    for (int i = 0; i < 10; i++) 
    {
        Console.WriteLine("รอบที่ " + i); 
    }
    
    ```
    
2. **`while` loop:** เหมาะสำหรับการทำซ้ำที่เราไม่รู้จำนวนครั้งที่แน่นอน  แต่รู้เงื่อนไขในการหยุด  เช่น  วนลูปอ่านข้อมูลจากไฟล์จนกว่าจะจบไฟล์
    
    ```csharp
    int number = 1;
    while (number <= 5)
    {
        Console.WriteLine(number);
        number++;
    }
    ```
    
3. **`do-while` loop:** คล้ายกับ `while` loop  แต่จะทำคำสั่งในลูปอย่างน้อย 1 ครั้งก่อน  แล้วค่อยตรวจสอบเงื่อนไข
    
    ```csharp
    int number = 1;
    do
    {
        Console.WriteLine(number);
        number++;
    } while (number <= 5);
    ```
    

**ส่วนประกอบสำคัญของ Looping**

- **เงื่อนไข (Condition):** เป็นตัวกำหนดว่าจะวนลูปต่อไปหรือไม่ ถ้าเงื่อนไขเป็นจริง ก็จะทำซ้ำ ถ้าเป็นเท็จ ก็จะออกจากลูป
- **ตัวนับ (Counter):** ใช้ติดตามจำนวนครั้งที่วนลูป หรือใช้เป็น index ในการเข้าถึงข้อมูลใน Array
- **คำสั่งในลูป (Loop Body):** เป็นส่วนของโค้ดที่จะถูก 실행ซ้ำๆ ภายในลูป

**การเลือกใช้ Looping**

- ถ้ารู้จำนวนครั้งที่แน่นอน ให้ใช้ `for` loop
- ถ้าไม่รู้จำนวนครั้ง แต่รู้เงื่อนไขในการหยุด ให้ใช้ `while` loop
- ถ้าต้องการให้ทำคำสั่งในลูปอย่างน้อย 1 ครั้ง ให้ใช้ `do-while` loop

**ตัวอย่างการใช้งาน Looping**

```csharp
// แสดงสูตรคูณแม่ 2
for (int i = 1; i <= 12; i++)
{
    Console.WriteLine("2 x " + i + " = " + (2 * i));
}

// ถามชื่อผู้ใช้จนกว่าจะพิมพ์ "exit"
string input = "";
while (input != "exit")
{
    Console.Write("Enter your name (or 'exit' to quit): ");
    input = Console.ReadLine();
    Console.WriteLine("Hello, " + input + "!");
}
```

**ข้อควรระวัง**

- ระวัง **Infinite Loop** คือ ลูปที่วนซ้ำไม่สิ้นสุด เพราะเงื่อนไขเป็นจริงตลอด ทำให้โปรแกรมค้าง
- ควรเลือกใช้ Looping ให้เหมาะสมกับงาน เพื่อให้โค้ดทำงานได้อย่างมีประสิทธิภาพ

การทำซ้ำเป็นเครื่องมือสำคัญที่ช่วยให้เราเขียนโปรแกรมได้อย่างมีประสิทธิภาพ  ลองฝึกเขียนโค้ดและทดลองใช้งาน Looping ดูนะครับ  มีคำถามอะไรก็ถามได้เลยครับ
