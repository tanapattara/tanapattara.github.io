# Array

**Array คืออะไร?**

ลองนึกภาพว่าเรามีกล่องหลายๆ ใบเรียงต่อกันเป็นแถว แต่ละใบมีหมายเลขกำกับตั้งแต่ 0 ไปเรื่อยๆ  เราสามารถเก็บของไว้ในกล่องแต่ละใบได้  Array ก็คล้ายๆ กันครับ  มันเป็นเหมือนที่เก็บข้อมูลหลายๆ ตัวแปร  ที่เรียงต่อกันในหน่วยความจำ  โดยแต่ละตัวแปรใน Array จะมีชนิดข้อมูลเหมือนกัน  เช่น  เป็นตัวเลขจำนวนเต็ม (int)  หรือตัวอักษร (char) ทั้งหมด  และเราสามารถเข้าถึงข้อมูลในแต่ละช่องของ Array ได้ด้วย "index" หรือหมายเลขประจำช่องของมัน  ซึ่ง index จะเริ่มต้นที่ 0 เสมอ

**การประกาศ Array**

ในภาษา C#  เราประกาศ Array ได้ง่ายๆ  โดยระบุชนิดข้อมูลของ Array  ตามด้วยเครื่องหมายวงเล็บเหลี่ยม `[]`  และชื่อของ Array  เช่น

```csharp
int[] numbers;  // ประกาศ Array ชื่อ numbers ที่เก็บข้อมูลชนิด int
string[] names; // ประกาศ Array ชื่อ names ที่เก็บข้อมูลชนิด string
```

**การสร้าง Array**

หลังจากประกาศ Array แล้ว  เราต้องสร้าง Array  โดยกำหนดขนาดหรือจำนวนช่องของ Array  พร้อมกับกำหนดค่าเริ่มต้นให้กับแต่ละช่อง  เช่น

```csharp
numbers = new int[5]; // สร้าง Array ชื่อ numbers มี 5 ช่อง
names = new string[] { "John", "Jane", "Peter", "Mary" }; // สร้าง Array ชื่อ names มี 4 ช่อง พร้อมกำหนดค่าเริ่มต้น
```

**การเข้าถึงข้อมูลใน Array**

เราสามารถเข้าถึงข้อมูลใน Array ได้โดยใช้ index  โดย index จะเริ่มต้นที่ 0  เช่น

```csharp
int firstNumber = numbers[0]; // อ่านค่าในช่องแรกของ Array numbers
string secondName = names[1]; // อ่านค่าในช่องที่สองของ Array names
```

**ประเภทของ Array**

- **Single-Dimensional Array:** Array ธรรมดาที่มีมิติเดียว เหมือนตัวอย่างที่ผ่านมา
- **Multidimensional Array:** Array ที่มีมากกว่าหนึ่งมิติ เช่น Array สองมิติ ที่เหมือนกับตาราง มีทั้งแถวและคอลัมน์

**ข้อดีของการใช้ Array**

- จัดเก็บข้อมูลหลายๆ ตัวแปรที่มีชนิดข้อมูลเดียวกันได้อย่างเป็นระเบียบ
- เข้าถึงข้อมูลได้ง่ายและรวดเร็วด้วย index
- เหมาะสำหรับการจัดการข้อมูลที่มีโครงสร้าง เช่น ตารางข้อมูล

Array เป็นโครงสร้างข้อมูลพื้นฐานที่สำคัญในภาษา C#  ที่ช่วยให้เราจัดเก็บและจัดการข้อมูลได้อย่างมีประสิทธิภาพ  การเข้าใจวิธีการใช้งาน Array จะเป็นพื้นฐานสำคัญในการเขียนโปรแกรมที่ซับซ้อนต่อไป
