# ภาพรวมรายวิชา Mobile Application Development

รายวิชานี้มุ่งพัฒนาแอปมือถือข้ามแพลตฟอร์มด้วย **React Native + Expo + TypeScript + Expo Router** ผ่านการสร้าง Campus Events Mobile อย่างต่อเนื่อง 14 สัปดาห์ ผู้เรียนจะเชื่อมโยงแนวคิด UI, Navigation, State, Networking, Offline data, Security, Device APIs, Testing และ Release เข้ากับผลิตภัณฑ์เดียว

## คำอธิบายรายวิชา

ศึกษาสถาปัตยกรรม คุณลักษณะ และข้อจำกัดของอุปกรณ์เคลื่อนที่ กระบวนการพัฒนาแอปข้ามแพลตฟอร์ม ส่วนติดต่อผู้ใช้ การจัดการสถานะและข้อมูลถาวร การสื่อสารกับบริการภายนอก การขอสิทธิ์และเข้าถึงความสามารถของอุปกรณ์ ความมั่นคงปลอดภัย การทดสอบ การปรับประสิทธิภาพ และกระบวนการสร้างรุ่นสำหรับเผยแพร่ พร้อมฝึกปฏิบัติผ่านโครงงาน

## ผลลัพธ์การเรียนรู้

เมื่อจบรายวิชา ผู้เรียนสามารถ:

- ออกแบบและพัฒนาแอป React Native ด้วย Expo และ TypeScript
- จัดโครงสร้างเส้นทางด้วย Expo Router และอธิบาย Stack, Tabs, Dynamic route และ Deep link
- จัดการ Form, State, REST API, Cache และ Offline experience อย่างเป็นระบบ
- เลือกใช้ AsyncStorage, SecureStore และ SQLite ให้ตรงกับชนิดข้อมูล
- ขอ Permission และใช้ Camera, Image Picker, Location, Maps และ Notifications โดยมี UX เมื่อผู้ใช้ปฏิเสธ
- ป้องกัน Route, รักษา Session และอธิบายขอบเขตของ Biometrics
- ตรวจคุณภาพด้าน Testing, Performance, Accessibility และ Security
- สร้าง Development, Preview และ Production Build รวมถึงวางแผน EAS Update

## การจัดเวลาและการประเมิน

| ส่วน | เวลา/น้ำหนักแนะนำ |
| --- | ---: |
| บรรยายและสาธิต | ประมาณ 1 ชั่วโมงต่อสัปดาห์ |
| Lab และ Project studio | ประมาณ 2 ชั่วโมงต่อสัปดาห์ |
| งานสะสมรายสัปดาห์ | 35% |
| Project checkpoints | 30% |
| Final build และการนำเสนอ | 25% |
| การอธิบายเหตุผลและ Code review | 10% |

<Callout type="warning">
  ห้ามเก็บรหัสผ่าน, access token, API secret หรือข้อมูลส่วนบุคคลจริงไว้ใน source code, log หรือ repository สาธารณะ
</Callout>

## เครื่องมือหลัก

- Node.js รุ่น LTS, Git และโปรแกรมแก้ไขโค้ด
- Android Studio Emulator หรืออุปกรณ์ Android จริง
- Expo Go สำหรับบทพื้นฐาน และ Development Build เมื่อใช้ความสามารถที่ Expo Go ไม่รองรับ
- Expo CLI ผ่าน `npx expo` และ EAS CLI ผ่าน `npx eas-cli@latest`
