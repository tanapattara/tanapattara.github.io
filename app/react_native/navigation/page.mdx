# Navigation

รายวิชาใช้ [Expo Router ในสัปดาห์ 4](/react_native/week-04) เป็นแนวทางหลัก React Navigation ยังคงเป็นพื้นฐานที่ Expo Router ใช้ภายใน แต่ไม่สอนเป็นเส้นทางหลักคู่ขนาน และไม่ต้องสร้าง `NavigationContainer` ซ้ำในโปรเจกต์ Expo Router
