# Campus Events Mobile — โปรเจกต์ประจำวิชา

ผู้เรียนพัฒนาแอปค้นหา บันทึก และลงทะเบียนกิจกรรมมหาวิทยาลัยจาก codebase เดียวตลอด 14 สัปดาห์ แต่ละ Milestone เพิ่มความสามารถที่ใช้ต่อในสัปดาห์ถัดไป ไม่สร้างแอปใหม่แยกกันทุกครั้ง

## Product scope

- ดูรายการและรายละเอียดกิจกรรม
- ค้นหา กรอง และบันทึกรายการโปรด
- Login/Logout และลงทะเบียนกิจกรรมผ่าน protected route
- ทำงานกับ REST API และแสดง cache เมื่อ Offline
- ถ่าย/เลือกรูป เลือกสถานที่ และตั้ง Event reminder
- รองรับ Loading, Empty, Error, Permission denied และ Accessibility
- มี Test suite, Preview Build และ Production release plan

## Technology baseline

```text
React Native + Expo + TypeScript + Expo Router
fetch + typed service/repository
AsyncStorage + SecureStore + SQLite introduction
Expo Camera/Image Picker + Location + Notifications
EAS Development / Preview / Production + EAS Update
```

## แบบจำลองข้อมูลหลัก

```tsx
export type CampusEvent = {
  id: string;
  title: string;
  description: string;
  startsAt: string; // ISO 8601
  imageUrl?: string;
  location: {
    name: string;
    latitude: number;
    longitude: number;
  };
};
```

## Milestone 2 — UI และ Components

### เป้าหมายการเรียนรู้

สร้าง typed reusable components และ responsive list UI

### ความสามารถที่ต้องมี

- `EventCard`, Event list และ mock data
- Loading, Empty และ Error states
- Safe area, responsive layout และ accessibility labels

### สิ่งที่ส่ง

Component catalog และภาพสองขนาดหน้าจอ

## Milestone 3 — Navigation

### เป้าหมายการเรียนรู้

ออกแบบ file-based routing, Stack, Tabs, Dynamic routes และ Deep links

### ความสามารถที่ต้องมี

- `/events`, `/events/[id]`, `/favorites`, `/profile`
- Not found/invalid ID state
- Android Back และ deep link behavior

### สิ่งที่ส่ง

Route diagram และวิดีโอสาธิต navigation/deep link

### Checklist

- [ ] Expo Router เป็นเส้นทางหลักและไม่มี NavigationContainer ซ้ำ
- [ ] ส่งเฉพาะ ID ผ่าน route และ validate ก่อนใช้
- [ ] Deep link เข้า Detail ได้โดยตรง

## Milestone 4 — Forms และ State

### เป้าหมายการเรียนรู้

จัด ownership ของ state และสร้าง form ที่ให้ feedback ชัดเจน

### ความสามารถที่ต้องมี

- Event search และ shared Favorite state
- Event registration form พร้อม validation
- Reducer/custom hooks และ submitting state

### สิ่งที่ส่ง

State diagram, form demo และ reducer/hook

### Checklist

- [ ] ไม่มี derived state ซ้ำโดยไม่จำเป็น
- [ ] Error อยู่ใกล้ field และอ่านด้วย screen reader ได้
- [ ] ป้องกัน submit ซ้ำและรักษาค่าเมื่อส่งล้มเหลว

## Milestone 5 — API

### เป้าหมายการเรียนรู้

เชื่อม REST API อย่างทนทานและแยก network boundary

### ความสามารถที่ต้องมี

- GET event list/detail และ POST registration
- Loading, Error, Retry และ Pull-to-refresh
- Request cancellation และ runtime response validation

### สิ่งที่ส่ง

API contract, service code และ network-state test matrix

### Checklist

- [ ] ตรวจ `response.ok`
- [ ] Screen ไม่เรียก `fetch` โดยตรง
- [ ] Retry ไม่สร้าง registration ซ้ำ

## Milestone 6 — Offline และ Cache

### เป้าหมายการเรียนรู้

เลือก storage ตามชนิดข้อมูลและออกแบบ offline-first read flow

### ความสามารถที่ต้องมี

- Event cache พร้อมเวลาอัปเดต
- SQLite proof-of-concept และ Offline banner

### สิ่งที่ส่ง

Storage matrix และวิดีโอ restart/offline flow

### Checklist

- [ ] Favorite คงอยู่หลัง restart
- [ ] Cache เก่าแสดงสถานะและเวลาอัปเดต
- [ ] Token ไม่อยู่ใน AsyncStorage/log

## Milestone 7 — Authentication
