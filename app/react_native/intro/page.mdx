# การเริ่มต้น React Native และ Expo

เนื้อหาหน้านี้ถูกรวมและปรับปรุงเป็น [สัปดาห์ 1: Mobile Development, React Native และ Expo](/react_native/week-01) แล้ว เพื่อให้ขั้นตอนติดตั้ง, Expo Go, Development Build, TypeScript และโครงสร้าง Expo Router อยู่ในบทเดียวกัน

ใช้คำสั่ง baseline ที่ผู้สอนประกาศ โดยไม่ต้องติดตั้ง CLI แบบ global:

```bash
npx create-expo-app@latest campus-events --template default@sdk-XX
cd campus-events
npx expo start
```
