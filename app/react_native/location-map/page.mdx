# Location and Map

## เครื่องมือและไลบรารีที่จำเป็น

ในการปฏิบัติตามบทเรียนนี้ จำเป็นต้องมีการติดตั้งและตั้งค่าเครื่องมือดังต่อไปนี้:

- **Node.js** และ **npm** (หรือ yarn)
- **Expo CLI**: เรียกผ่าน `npx expo` โดยไม่ติดตั้งแบบ global
- **Expo Go App**: ติดตั้งบนอุปกรณ์ทดสอบ (iOS หรือ Android)
- **ไลบรารีที่เกี่ยวข้อง**:
    - `expo-location`: สำหรับการเข้าถึงข้อมูลตำแหน่ง
    - `react-native-maps`: สำหรับการแสดงผลแผนที่

## ขั้นตอนการดำเนินงาน

### การสร้างโปรเจกต์ Expo

เริ่มต้นด้วยการสร้างโปรเจกต์ React Native ใหม่โดยใช้ Expo CLI

```bash
npx create-expo-app@latest location-map --template blank-typescript
```

จากนั้นเลือก Template ที่ต้องการ (แนะนำเป็น "blank") และเข้าไปยังไดเรกทอรีของโปรเจกต์

Bash

```bash
cd location-map
```

### การติดตั้งไลบรารี

ทำการติดตั้งไลบรารีที่จำเป็นสำหรับการเรียกใช้ตำแหน่งและแสดงแผนที่

```bash
npx expo install expo-location
npx expo install react-native-maps
```

การใช้ `npx expo install` จะช่วยให้มั่นใจได้ว่าเวอร์ชันของไลบรารีที่ติดตั้งนั้นเข้ากันได้กับเวอร์ชันของ Expo SDK ที่ใช้งานอยู่

### การขออนุญาตเข้าถึงตำแหน่ง (Requesting Location Permissions)

แอปพลิเคชันจำเป็นต้องได้รับอนุญาตจากผู้ใช้ก่อนจึงจะสามารถเข้าถึงข้อมูลตำแหน่งได้ เราจะใช้ `expo-location` ในการจัดการส่วนนี้

ในโปรเจกต์รายวิชาให้เพิ่มโค้ดใน route component เช่น `app/(tabs)/events/map.tsx`

**ตัวอย่างโค้ด: `app/(tabs)/events/map.tsx`**

```tsx
import React, { useState, useEffect } from 'react';
import { Platform, Text, View, StyleSheet } from 'react-native';
import * as Location from 'expo-location';

export default function App() {
  const [location, setLocation] = useState(null);
  const [errorMsg, setErrorMsg] = useState(null);

  useEffect(() => {
    (async () => {
      // ขออนุญาตเข้าถึงตำแหน่ง
      let { status } = await Location.requestForegroundPermissionsAsync();
      if (status !== 'granted') {
        setErrorMsg('Permission to access location was denied');
        return;
      }

      // ดึงข้อมูลตำแหน่งปัจจุบัน
      let currentLocation = await Location.getCurrentPositionAsync({});
      setLocation(currentLocation);
    })();
  }, []);

  let text = 'Waiting..';
  if (errorMsg) {
    text = errorMsg;
  } else if (location) {
    text = JSON.stringify(location);
  }

  return (
    <View style={styles.container}>
      <Text style={styles.paragraph}>{text}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 20,
  },
  paragraph: {
    fontSize: 18,
    textAlign: 'center',
  },
});
```

**คำอธิบายโค้ด:**

- `useEffect` ถูกใช้เพื่อเรียกฟังก์ชันขออนุญาตทันทีที่คอมโพเนนต์ถูกโหลด
- `Location.requestForegroundPermissionsAsync()` จะแสดงกล่องโต้ตอบเพื่อขออนุญาตจากผู้ใช้
- หากผู้ใช้อนุญาต (`status === 'granted'`) ฟังก์ชัน `Location.getCurrentPositionAsync({})` จะถูกเรียกเพื่อดึงค่าพิกัดปัจจุบัน
- ข้อมูลตำแหน่งที่ได้จะถูกเก็บไว้ใน `state` ชื่อ `location` และแสดงผลเป็นข้อความ JSON บนหน้าจอ

### การแสดงผลแผนที่ OpenStreetMap

หลังจากที่ได้ข้อมูลตำแหน่งแล้ว ขั้นตอนต่อไปคือการนำไปแสดงผลบนแผนที่โดยใช้ `react-native-maps`

**ตัวอย่างโค้ด: `app/(tabs)/events/map.tsx` (ฉบับปรับปรุง)**

```tsx
import React, { useState, useEffect } from 'react';
import { Text, View, StyleSheet, ActivityIndicator } from 'react-native';
import MapView, { Marker, PROVIDER_DEFAULT } from 'react-native-maps';
import * as Location from 'expo-location';

export default function App() {
  const [location, setLocation] = useState(null);
  const [errorMsg, setErrorMsg] = useState(null);

  useEffect(() => {
    (async () => {
      let { status } = await Location.requestForegroundPermissionsAsync();
      if (status !== 'granted') {
        setErrorMsg('Permission to access location was denied');
        return;
      }
      let currentLocation = await Location.getCurrentPositionAsync({});
      setLocation(currentLocation);
    })();
  }, []);

  if (errorMsg) {
    return (
      <View style={styles.container}>
        <Text style={styles.paragraph}>{errorMsg}</Text>
      </View>
    );
  }

  if (!location) {
    return (
      <View style={styles.container}>
        <ActivityIndicator size="large" />
        <Text>Loading map and location...</Text>
      </View>
    );
  }

  // กำหนด region เริ่มต้นของแผนที่ให้เป็นตำแหน่งปัจจุบันของผู้ใช้
  const initialRegion = {
    latitude: location.coords.latitude,
    longitude: location.coords.longitude,
    latitudeDelta: 0.0922,
    longitudeDelta: 0.0421,
  };

  return (
    <View style={styles.container}>
      <MapView
        style={styles.map}
        provider={PROVIDER_DEFAULT} // ใช้ Map Provider เริ่มต้น (ซึ่งมักจะเป็น OSM บน Expo Go)
        initialRegion={initialRegion}
        showsUserLocation={true} // แสดงจุดสีน้ำเงินสำหรับตำแหน่งปัจจุบัน
      >
        <Marker
          coordinate={{
            latitude: location.coords.latitude,
            longitude: location.coords.longitude,
          }}
          title={"Your Location"}
          description={"This is your current location"}
        />
      </MapView>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
  map: {
    width: '100%',
    height: '100%',
  },
  paragraph: {
    fontSize: 18,
    textAlign: 'center',
  },
});
```

**คำอธิบายโค้ด:**

1. **การนำเข้า (Import)**: นำเข้า `MapView` และ `Marker` จาก `react-native-maps`
2. **การจัดการสถานะการโหลด (Loading State)**: เพิ่มเงื่อนไขเพื่อแสดง `ActivityIndicator` (วงกลมหมุน) ขณะที่กำลังรอข้อมูลตำแหน่ง เพื่อปรับปรุงประสบการณ์ผู้ใช้
3. **MapView Component**:
    - `style={styles.map}`: กำหนดให้แผนที่แสดงผลเต็มหน้าจอ
    - `provider={PROVIDER_DEFAULT}`: ใน Expo Go ค่านี้จะใช้แผนที่ของ Apple (บน iOS) หรือ Google Maps ที่มีข้อมูลจาก OSM (บน Android) เป็นพื้นฐาน หากต้องการใช้ OSM โดยตรงในแอปพลิเคชันที่ Build แล้ว สามารถกำหนดค่า `urlTemplate` ได้
    - `initialRegion`: ตั้งค่ามุมมองเริ่มต้นของแผนที่ให้ซูมไปยังตำแหน่งของผู้ใช้ โดยใช้ค่าละติจูดและลองจิจูดที่ได้รับมา `latitudeDelta` และ `longitudeDelta` เป็นค่าที่ใช้กำหนดระดับการซูม
    - `showsUserLocation={true}`: เปิดใช้งานการแสดงจุดสีน้ำเงินซึ่งเป็นตำแหน่งของผู้ใช้แบบเรียลไทม์
4. **Marker Component**:
    - ใช้คอมโพเนนต์ `<Marker />` ภายใน `<MapView />` เพื่อปักหมุด
    - `coordinate`: กำหนดพิกัดที่จะปักหมุด โดยใช้ข้อมูลจาก `location.coords`
    - `title` และ `description`: ข้อความที่จะแสดงเมื่อผู้ใช้แตะที่หมุด

## สรุป

ในบทเรียนนี้ ผู้เรียนได้เรียนรู้กระบวนการที่สำคัญในการพัฒนาแอปพลิเคชันที่เกี่ยวข้องกับตำแหน่ง เริ่มตั้งแต่การขอสิทธิ์เข้าถึงตำแหน่งของผู้ใช้ด้วย `expo-location` การดึงค่าพิกัดละติจูดและลองจิจูด และสุดท้ายคือการนำค่าพิกัดดังกล่าวมาแสดงผลเป็นหมุดบนแผนที่ด้วย `react-native-maps` ซึ่งเป็นพื้นฐานสำคัญที่สามารถนำไปต่อยอดเพื่อสร้างฟังก์ชันที่ซับซ้อนขึ้นได้ เช่น การติดตามตำแหน่งแบบเรียลไทม์, การคำนวณระยะทาง, หรือการแสดงผลข้อมูลตามตำแหน่งที่ตั้ง เป็นต้น
