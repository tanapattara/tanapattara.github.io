# Core Components

หลักสูตรย้ายเนื้อหา Components, Props, State และ Events ไปยัง [สัปดาห์ 2](/react_native/week-02) แล้ว หน้าใหม่ใช้ TypeScript และ `EventCard` ของ Campus Events Mobile เป็นตัวอย่างหลัก

URL นี้เก็บไว้สำหรับลิงก์เดิม กรุณาเรียนจากบทปัจจุบันเพื่อให้ตัวอย่าง Props และ Component contract ตรงกับสัปดาห์ถัดไป
