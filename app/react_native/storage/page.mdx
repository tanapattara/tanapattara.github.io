# Local Storage และ Offline

เรียนเนื้อหาปัจจุบันที่ [สัปดาห์ 7: Local Storage และ Offline Applications](/react_native/week-07)

แนวทางของรายวิชา:

- AsyncStorage สำหรับ key/value ทั่วไปและ cache ขนาดเล็ก
- SecureStore สำหรับ token หรือข้อมูลอ่อนไหวขนาดเล็ก ไม่เก็บรหัสผ่านผู้ใช้
- SQLite สำหรับข้อมูลถาวรที่มีโครงสร้างและต้องค้นหา
