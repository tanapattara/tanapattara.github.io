# EAS Build และ EAS Update

เนื้อหาการสร้าง Development, Preview และ Production Build รวมถึง EAS Update ที่ตั้งค่า `expo-updates`, channel และ runtime version ครบถ้วน อยู่ใน [สัปดาห์ 14: Build, Release และ Presentation](/react_native/week-14)

URL นี้เก็บไว้สำหรับลิงก์เดิม ตัวอย่าง configuration ที่ไม่สมบูรณ์ถูกนำออกเพื่อให้ผู้เรียนใช้ workflow ปัจจุบันเพียงชุดเดียว
