# Local Authentication

บทเรียนนี้มีวัตถุประสงค์เพื่อนำเสนอวิธีการใช้งานโมดูล **`expo-local-authentication`** ในแอปพลิเคชัน React Native ที่สร้างด้วย Expo เพื่อเปิดใช้งานการยืนยันตัวตนทางชีวมิติ (Biometric Authentication) เช่น ลายนิ้วมือ (Touch ID/Fingerprint) หรือการจดจำใบหน้า (Face ID) ซึ่งเป็นคุณสมบัติสำคัญในการเพิ่มความปลอดภัยและความสะดวกสบายให้กับผู้ใช้

## **ขั้นตอนที่ 1: สร้างโปรเจตและการติดตั้งโมดูล**

เริ่มต้นด้วยการสร้างโปรเจกต์ Expo หรือใช้โปรเจกต์ที่มีอยู่ และทำการติดตั้งโมดูล `expo-local-authentication` โดยใช้คำสั่งต่อไปนี้:

```bash
npx create-expo-app@latest local-authentication --template blank-typescript
npx expo install expo-local-authentication
```

## ขั้นตอนที่ 2: การตั้งค่าสิทธิ์การเข้าถึง (สำหรับ iOS)

สำหรับอุปกรณ์ iOS ที่มีการรองรับ **Face ID** ท่านจำเป็นต้องเพิ่มคำอธิบายการใช้งาน (Usage Description) ในไฟล์คอนฟิกูเรชันของ Expo (`app.json` หรือ `app.config.js`) เพื่อให้แอปพลิเคชันสามารถใช้งานคุณสมบัตินี้ได้ หากไม่เพิ่มการตั้งค่านี้ ระบบจะเลือกใช้รหัสผ่านเครื่อง (Device Passcode) แทน Face ID
ไฟล์ `app.json`:

```json
{
  "expo": {
    // ... การตั้งค่าอื่น ๆ
    "ios": {
      "infoPlist": {
        "NSFaceIDUsageDescription": "อนุญาตให้ $(PRODUCT_NAME) ใช้ Face ID เพื่อยืนยันตัวตนของคุณ"
      }
    }
  }
}

```

**คำอธิบาย:**

- `NSFaceIDUsageDescription`: เป็นคีย์ที่จำเป็นสำหรับ iOS เพื่อให้ผู้ใช้ทราบถึงวัตถุประสงค์ของการขอใช้ Face ID
- ข้อความที่ใส่ไว้จะถูกแสดงในหน้าต่างแจ้งเตือนสิทธิ์ (Permission Alert) เมื่อแอปพลิเคชันเรียกใช้ Face ID ครั้งแรก

สำหรับ Android โมดูลจะทำการเพิ่มสิทธิ์ที่จำเป็นให้โดยอัตโนมัติ

## ขั้นตอนที่ 3: การสร้างคอมโพเนนต์การยืนยันตัวตน

เราจะสร้างคอมโพเนนต์ React ที่ใช้ฟังก์ชันการทำงานหลักจาก `expo-local-authentication` เพื่อตรวจสอบความสามารถของอุปกรณ์และเรียกใช้งานการยืนยันตัวตน

**โค้ดตัวอย่างในไฟล์ `app/unlock.tsx`**

```tsx
import React, { useState, useEffect } from 'react';
import { View, Text, Button, StyleSheet, Alert } from 'react-native';
import * as LocalAuthentication from 'expo-local-authentication';

export default function App() {
  // State สำหรับเก็บสถานะว่าอุปกรณ์รองรับ Biometrics หรือไม่
  const [isBiometricSupported, setIsBiometricSupported] = useState(false);
  // State สำหรับเก็บสถานะว่ามีการลงทะเบียน Biometrics ไว้ในเครื่องหรือไม่
  const [isEnrolled, setIsEnrolled] = useState(false);
  // State สำหรับเก็บสถานะการยืนยันตัวตน
  const [isAuthenticated, setIsAuthenticated] = useState(false);

  // useEffect จะทำงานเมื่อคอมโพเนนต์ถูกโหลด
  useEffect(() => {
    // ฟังก์ชันตรวจสอบคุณสมบัติ Biometric ของอุปกรณ์
    (async () => {
      // 1. ตรวจสอบว่าอุปกรณ์มีฮาร์ดแวร์รองรับ Biometrics หรือไม่
      const hasHardware = await LocalAuthentication.hasHardwareAsync();
      setIsBiometricSupported(hasHardware);

      // 2. ตรวจสอบว่ามีการลงทะเบียนลายนิ้วมือหรือใบหน้าไว้ในเครื่องหรือไม่
      if (hasHardware) {
        const enrolled = await LocalAuthentication.isEnrolledAsync();
        setIsEnrolled(enrolled);
      }
    })();
  }, []);

  // ฟังก์ชันสำหรับการเรียกใช้หน้าต่างยืนยันตัวตน
  const handleBiometricAuth = async () => {
    // ตรวจสอบขั้นแรก: หากไม่รองรับฮาร์ดแวร์ หรือไม่มีการลงทะเบียน
    if (!isBiometricSupported || !isEnrolled) {
      Alert.alert(
        'การยืนยันตัวตน', 
        'อุปกรณ์ไม่รองรับ Biometrics หรือยังไม่ได้ลงทะเบียนลายนิ้วมือ/ใบหน้า'
      );
      return;
    }

    try {
      // เรียกใช้เมธอด authenticateAsync()
      const result = await LocalAuthentication.authenticateAsync({
        promptMessage: 'โปรดยืนยันตัวตนเพื่อเข้าสู่ระบบ', // ข้อความที่แสดงใน Prompt
        // 'disableDeviceFallback: true' เพื่อป้องกันการกลับไปใช้รหัสผ่านเครื่อง
      });

      if (result.success) {
        setIsAuthenticated(true);
        Alert.alert('สำเร็จ', 'ยืนยันตัวตนสำเร็จ!');
      } else {
        setIsAuthenticated(false);
        // แสดงข้อความแจ้งเตือนตามข้อผิดพลาดที่ได้รับ (เช่น ผู้ใช้กดยกเลิก)
        Alert.alert('ล้มเหลว', `การยืนยันตัวตนล้มเหลว: ${result.error}`);
      }
    } catch (error) {
      console.error('Biometric authentication error:', error);
      Alert.alert('ข้อผิดพลาด', 'เกิดข้อผิดพลาดในการยืนยันตัวตน');
    }
  };

  return (
    <View style={styles.container}>
      <Text style={styles.heading}>Biometric Authentication Example</Text>
      
      {/* แสดงสถานะการรองรับและลงทะเบียน */}
      <Text>รองรับ Biometric Hardware: {isBiometricSupported ? 'ใช่' : 'ไม่'}</Text>
      <Text>มีการลงทะเบียน Biometric: {isEnrolled ? 'ใช่' : 'ไม่'}</Text>
      
      <View style={styles.spacer} />

      {/* ปุ่มสำหรับเรียกใช้การยืนยันตัวตน */}
      <Button
        title="ยืนยันตัวตนด้วย Biometrics"
        onPress={handleBiometricAuth}
        disabled={!isBiometricSupported || !isEnrolled}
      />
      
      <View style={styles.spacer} />
      
      {/* แสดงผลลัพธ์การยืนยันตัวตน */}
      {isAuthenticated ? (
        <Text style={styles.successText}>🔒 เข้าสู่ระบบสำเร็จแล้ว</Text>
      ) : (
        <Text style={styles.failText}>🔓 ยังไม่ได้เข้าสู่ระบบ</Text>
      )}

    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    padding: 20,
    backgroundColor: '#f5f5f5',
  },
  heading: {
    fontSize: 20,
    fontWeight: 'bold',
    marginBottom: 20,
  },
  spacer: {
    height: 20,
  },
  successText: {
    marginTop: 20,
    color: 'green',
    fontSize: 16,
    fontWeight: 'bold',
  },
  failText: {
    marginTop: 20,
    color: 'red',
    fontSize: 16,
  },
});
```

## คำอธิบายโค้ดโดยละเอียด

### 1. การนำเข้า (Import)

JavaScript

```tsx
import * as LocalAuthentication from 'expo-local-authentication';
```

เราทำการนำเข้าโมดูล `expo-local-authentication` ทั้งหมดภายใต้ชื่อ `LocalAuthentication` เพื่อใช้งานเมธอดที่เกี่ยวข้องกับการยืนยันตัวตน

### 2. การตรวจสอบคุณสมบัติ (Initial Checks)

ภายใน `useEffect` เราเรียกใช้เมธอดที่สำคัญสองตัว:

- **`LocalAuthentication.hasHardwareAsync()`**:
    - **วัตถุประสงค์:** ตรวจสอบว่าอุปกรณ์ที่กำลังใช้งานมีฮาร์ดแวร์สำหรับ Biometrics (เช่น เซ็นเซอร์ลายนิ้วมือ หรือกล้อง Face ID) หรือไม่
    - **ผลลัพธ์:** ส่งค่า Promise ที่คืนค่าเป็นบูลีน (`true`/`false`)
- **`LocalAuthentication.isEnrolledAsync()`**:
    - **วัตถุประสงค์:** ตรวจสอบว่าผู้ใช้ได้ลงทะเบียนข้อมูล Biometrics (เช่น ลายนิ้วมือหรือใบหน้า) ไว้ในเครื่องเพื่อใช้ในการยืนยันตัวตนแล้วหรือไม่
    - **ผลลัพธ์:** ส่งค่า Promise ที่คืนค่าเป็นบูลีน (`true`/`false`)

การตรวจสอบเหล่านี้มีความจำเป็นอย่างยิ่งเพื่อไม่ให้แสดงปุ่มยืนยันตัวตนหรือเรียกใช้ฟังก์ชันที่ไม่สามารถทำงานได้จริงบนอุปกรณ์นั้น ๆ

### 3. การเรียกใช้งานการยืนยันตัวตน (`handleBiometricAuth`)

เมธอดหลักในการเรียกใช้งานการยืนยันตัวตนคือ **`LocalAuthentication.authenticateAsync(options)`**

- **`promptMessage: 'โปรดยืนยันตัวตนเพื่อเข้าสู่ระบบ'`**: เป็นพารามิเตอร์ที่ใช้กำหนดข้อความที่จะปรากฏในหน้าต่างแจ้งเตือน (Biometric Prompt) เพื่อบอกผู้ใช้ถึงวัตถุประสงค์ของการยืนยันตัวตน
- **การจัดการผลลัพธ์**: เมธอดนี้จะคืนค่า Promise ที่ Resolve เป็นอ็อบเจกต์ผลลัพธ์ (`LocalAuthenticationResult`) ซึ่งมีคุณสมบัติหลักคือ:
    - **`success`**: ค่าบูลีนที่ระบุว่าการยืนยันตัวตนสำเร็จหรือไม่
    - **`error`**: (ถ้ามี) รหัสข้อผิดพลาดในกรณีที่การยืนยันตัวตนล้มเหลว (เช่น 'user_cancel', 'not_enrolled', 'system_cancel')

หาก `result.success` เป็น `true` แสดงว่าผู้ใช้ได้ยืนยันตัวตนสำเร็จแล้ว และสามารถดำเนินการเข้าสู่ส่วนที่ได้รับการป้องกันได้

### ข้อควรจำและข้อจำกัด

- **Face ID บน Expo Go:** Face ID บน iOS **ไม่รองรับ** ในแอปพลิเคชัน Expo Go จะต้องสร้าง **Development Build** หรือ **Standalone Build** เพื่อทดสอบคุณสมบัติ Face ID
- **Fallback Mechanism:** หากผู้ใช้พยายามยืนยันตัวตนด้วย Biometrics ล้มเหลวหลายครั้ง ระบบปฏิบัติการจะกลับไปใช้รหัสผ่านเครื่องโดยอัตโนมัติ เว้นแต่จะมีการตั้งค่า `disableDeviceFallback: true` ใน `authenticateAsync` ซึ่งจะทำให้แอปพลิเคชันต้องจัดการ Fallback ด้วยตนเอง
- **ความปลอดภัย:** `expo-local-authentication` เป็นการยืนยันตัวตนในเครื่อง (Local Authentication) เท่านั้น ไม่ได้เป็นการพิสูจน์ตัวตนระยะไกล (Remote Authentication) เพื่อเข้าสู่ระบบเซิร์ฟเวอร์โดยตรง หากต้องการใช้ Biometrics สำหรับการล็อกอินจริง มักจะใช้ควบคู่กับ `expo-secure-store` เพื่อจัดเก็บโทเค็นหรือข้อมูลรับรองที่เข้ารหัสไว้ในเครื่องอย่างปลอดภัย
