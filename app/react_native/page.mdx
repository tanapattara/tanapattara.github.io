# React Native + Expo + TypeScript — 14 สัปดาห์

หลักสูตรแบบ Project-based Learning สำหรับพัฒนาแอปมือถือข้ามแพลตฟอร์ม ตั้งแต่การเตรียมเครื่องมือจนถึงการสร้าง Preview/Production Build ผู้เรียนจะพัฒนา **Campus Events Mobile** จาก codebase เดียวต่อเนื่องตลอดภาคการศึกษา

<Callout type="info">
  Technology baseline ของรายวิชาคือ React Native, Expo, TypeScript และ Expo Router ตัวอย่างทุกบทใช้ `.tsx`, `npx expo` และ `npx expo install`
</Callout>

## รูปแบบการเรียน

แต่ละสัปดาห์ใช้เวลาประมาณ 3 ชั่วโมง: บรรยายและสาธิต 1 ชั่วโมง ปฏิบัติการ 2 ชั่วโมง ทุก Lab เพิ่มความสามารถให้ Campus Events Mobile เว้นแต่ระบุว่าเป็นแบบฝึกสั้น

## เส้นทางการเรียน 14 สัปดาห์

| สัปดาห์ | หัวข้อ | ผลงานปลายคาบ |
| --- | --- | --- |
| 1 | Mobile, React Native, Expo และ TypeScript | โปรเจกต์และหน้า Profile |
| 2 | Components, Props, State และ Events | `EventCard` ที่นำกลับมาใช้ซ้ำได้ |
| 3 | Styling, Responsive UI และ Lists | รายการกิจกรรมพร้อม Loading/Empty/Error |
| 4 | Expo Router และ Navigation | Events, Detail, Favorites และ Profile routes |
| 5 | Forms และ State Management | Search, Favorite และ Registration form |
| 6 | REST API และ Networking | โหลด/รีเฟรชกิจกรรมและส่ง Registration |
| 7 | Storage และ Offline-first | Favorite ถาวรและ Offline event list |
| 8 | Authentication และ Mobile Security | Session และ Protected registration route |
| 9 | Camera, Image Picker และ Permissions | ถ่าย/เลือกรูปกิจกรรมพร้อม Preview |
| 10 | Location และ Maps | ตำแหน่งปัจจุบันและหมุดสถานที่จัดงาน |
| 11 | Notifications และ Platform APIs | Event reminder ที่เปิด Detail ด้วย deep link |
| 12 | Architecture, Performance และ Accessibility | Refactor และ Quality audit |
| 13 | Testing และ Debugging | Test suite และ EAS Preview Build |
| 14 | Build, Release และ Presentation | Production candidate และการนำเสนอ |
