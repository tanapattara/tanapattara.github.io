# ติดตั้งและตั้งค่า Expo

บทติดตั้งเดิมถูกรวมไว้ใน [สัปดาห์ 1](/react_native/week-01) เพื่อไม่ให้มีขั้นตอนซ้ำหรือโครงสร้าง `App.js` ที่ขัดกับ Expo Router

Template เริ่มต้นที่แนะนำคือค่า default ของ `create-expo-app` ซึ่งมี TypeScript และ Expo Router พร้อมใช้งาน:

```bash
npx create-expo-app@latest campus-events
npx expo start
```

เมื่อต้องติดตั้ง Expo module ให้ใช้ `npx expo install <package>` เพื่อเลือกเวอร์ชันที่เข้ากับ Expo SDK ของโปรเจกต์
