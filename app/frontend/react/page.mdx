# React.js

React.js คือ JavaScript library สำหรับสร้าง UI ที่พัฒนาโดย Jordan Walke วิศวกรซอฟต์แวร์ของ Facebook

 การทำงาน:

> **หมายเหตุ**
> 💡 Facebook ใช้ภาษาหลัก ๆ ดังนี้: 
> - PHP: ส่วน Backend หลัก
> - Hack: ภาษาที่พัฒนาต่อยอดจาก PHP โดย Facebook เอง 
> - C++: ส่วนที่มีประสิทธิภาพสูง
> - Python: สำหรับงานด้าน Data Science และ Machine Learning
> - JavaScript: สำหรับส่วน Front-End และ React (Library ที่ Facebook พัฒนา)
> นอกจากนี้ยังมีภาษาอื่น ๆ ที่ใช้ในส่วนประกอบย่อย เช่น Java, Erlang, D, XHP และ GraphQL
>

- Component-Based: แบ่ง UI เป็นส่วนย่อย (Component) นำกลับมาใช้ซ้ำได้
- Virtual DOM: จำลอง DOM ของจริง ช่วยเพิ่มประสิทธิภาพการอัปเดต
- JSX: เขียน HTML ใน JavaScript ทำให้เขียนโค้ดง่ายขึ้น
- One-Way Data Flow: ข้อมูลไหลจากบนลงล่าง (Parent to Child) ง่ายต่อการจัดการ

ข้อดี:

- เร็วและมีประสิทธิภาพ
- ชุมชนใหญ่และมีเครื่องมือมากมาย

ข้อเสีย:

- เอกสารอาจไม่ละเอียดนัก
- ต้องมีความรู้ JavaScript พอสมควร
- ใช้เวลาในการเรียนรู้มาก
