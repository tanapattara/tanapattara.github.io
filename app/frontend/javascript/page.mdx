# JavaScript

## JAVASCRIPT คืออะไร

JavaScript (JS) คือ ภาษาด้านการเขียนโปรแกรม (Programming Language) ที่ใช้ในการเพิ่มความสามารถในการโต้ตอบและไดนามิกให้กับเว็บเพจ โดยทำงานร่วมกับ HTML และ CSS ซึ่ง HTML ทำหน้าที่สร้างโครงสร้างของเว็บเพจ CSS ทำหน้าที่ตกแต่งรูปแบบ ส่วน JavaScript จะทำหน้าที่เพิ่มความสามารถในการโต้ตอบกับผู้ใช้ เช่น การตรวจสอบข้อมูลในฟอร์ม การสร้างแอนิเมชัน การอัปเดตเนื้อหาบนเว็บเพจแบบเรียลไทม์ และอื่นๆ อีกมากมาย

## **JavaScript ทำงานอย่างไร**

JavaScript ทำงานโดยการฝังโค้ดลงในเว็บเพจ หรือเรียกใช้งานจากไฟล์ภายนอก เมื่อผู้ใช้เข้าชมเว็บเพจ เบราว์เซอร์จะอ่านและประมวลผลโค้ด JavaScript ทำให้เว็บเพจสามารถแสดงผลและโต้ตอบกับผู้ใช้ได้

```jsx
document.getElementById("myButton").addEventListener("click", function() {
  alert("Hello, World!");
});
```

## **ความสำคัญของ JavaScript**

JavaScript มีความสำคัญอย่างมากในการพัฒนาเว็บแอปพลิเคชันสมัยใหม่ JavaScript ช่วยให้เว็บไซต์มีความน่าสนใจและมีส่วนร่วมกับผู้ใช้มากขึ้น นอกจากนี้ JavaScript ยังเป็นภาษาที่ได้รับความนิยมอย่างมากในหมู่นักพัฒนาเว็บทั่วโลก

## ผู้ให้กําเนิด

ผู้ให้กําเนิด JavaScript คือ Brendan Eich ได้พัฒนา JavaScript ขึ้นในปี ค.ศ. 1995 ในขณะที่ทำงานอยู่ที่ Netscape Communications Corporation เดิมที JavaScript มีชื่อว่า Mocha ต่อมาเปลี่ยนเป็น LiveScript และสุดท้ายเป็น JavaScript

> **หมายเหตุ**
> 💡 Netscape เป็นบริษัทเทคโนโลยีที่โด่งดังในช่วงกลางทศวรรษ 1990 จากเว็บเบราว์เซอร์ Netscape Navigator ซึ่งเคยเป็นที่นิยมมากที่สุด ก่อนจะถูก Internet Explorer แซงหน้าในเวลาต่อมา
>

Brendan Eich ได้รับแรงบันดาลใจในการสร้าง JavaScript มาจากภาษาโปรแกรม Scheme และ Self โดยเขาต้องการสร้างภาษาสคริปต์ที่สามารถฝังลงในเว็บเพจได้ เพื่อเพิ่มความสามารถในการโต้ตอบและไดนามิกให้กับเว็บเพจ

JavaScript ได้รับความนิยมอย่างรวดเร็ว และกลายเป็นภาษาที่สำคัญที่สุดในการพัฒนาเว็บแอปพลิเคชันสมัยใหม่ ปัจจุบัน JavaScript ไม่ได้ใช้แค่ในเว็บเบราว์เซอร์เท่านั้น แต่ยังสามารถนำไปใช้พัฒนาแอปพลิเคชันบนเดสก์ท็อป, โมบายล์ และเซิร์ฟเวอร์ได้อีกด้วย
