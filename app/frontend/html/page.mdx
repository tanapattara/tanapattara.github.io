# HTML

## HTML คืออะไร

HTML หรือ Hypertext Markup Language คือ ภาษามาร์กอัป (Markup Language) ที่ใช้ในการสร้างโครงสร้างและเนื้อหาของเว็บเพจ โดยใช้แท็ก (tag) ต่างๆ เพื่อกำหนดองค์ประกอบต่างๆ ของหน้าเว็บ เช่น หัวข้อ, ย่อหน้า, ลิงก์, รูปภาพ, ตาราง เป็นต้น

## **HTML ทำงานอย่างไร**

HTML ทำงานโดยการใช้แท็ก (tag) ซึ่งอยู่ในเครื่องหมาย `&lt;` และ `&gt;` เพื่อกำหนดองค์ประกอบต่างๆ ของหน้าเว็บ แต่ละแท็กจะมีชื่อและอาจมีคุณสมบัติ (attribute) เพิ่มเติมเพื่อกำหนดลักษณะหรือพฤติกรรมขององค์ประกอบนั้น ๆ

**ตัวอย่างโค้ด HTML**

```html
<!DOCTYPE html>
<html>
  <head>
    <title>นี่คือหน้าเว็บของฉัน</title>
  </head>
  <body>
    <h1>ยินดีต้อนรับสู่หน้าเว็บของฉัน</h1>
    <p>นี่คือย่อหน้าแรกของหน้าเว็บ</p>
  </body>
</html>
```

> **หมายเหตุ**
> 💡 จะเห็นได้ว่า ทุกแท็กจะมี `แท็กเปิด` และ `แท็กปิด` เป็นคู่กันเสมอ เช่น `<h1></h1>` ดังนั้นการเขียน HTML ต้องเขียนทุกแท็กให้ครบถ้วน
>

## **ความสำคัญของ HTML**

HTML เป็นภาษาพื้นฐานที่สำคัญที่สุดในการสร้างเว็บไซต์ ทุกเว็บไซต์ที่คุณเห็นบนอินเทอร์เน็ตล้วนสร้างขึ้นด้วย HTML โดย HTML จะกำหนดโครงสร้างและเนื้อหาของหน้าเว็บ จากนั้นจึงใช้ CSS เพื่อตกแต่งหน้าตา และ JavaScript เพื่อเพิ่มความสามารถในการโต้ตอบกับผู้ใช้

## ผู้ให้กําเนิด

ผู้ให้กําเนิด HTML คือ **Tim Berners-Lee** นักวิทยาศาสตร์คอมพิวเตอร์ชาวอังกฤษ โดยเขาได้สร้าง HTML ขึ้นในปี ค.ศ. 1990 ในขณะที่ทำงานอยู่ที่ CERN (องค์กรวิจัยนิวเคลียร์ยุโรป) โดยมีจุดประสงค์เพื่อใช้ในการแบ่งปันข้อมูลระหว่างนักวิทยาศาสตร์

![Untitled](/images/classroom/frontend/html/untitled.png)

ในตอนแรก HTML เป็นภาษาที่เรียบง่าย มีแท็กเพียงไม่กี่แท็ก แต่ต่อมา HTML ได้รับการพัฒนาและปรับปรุงอย่างต่อเนื่อง โดยมีการเพิ่มแท็กและคุณสมบัติใหม่ๆ เข้ามา เพื่อให้สามารถสร้างเว็บเพจที่มีความซับซ้อนและสวยงามมากขึ้น

ปัจจุบัน HTML ได้กลายเป็นภาษาที่สำคัญที่สุดในการสร้างเว็บไซต์ ทุกเว็บไซต์ที่คุณเห็นบนอินเทอร์เน็ตล้วนสร้างขึ้นด้วย HTML โดย HTML จะกำหนดโครงสร้างและเนื้อหาของหน้าเว็บ จากนั้นจึงใช้ CSS เพื่อตกแต่งหน้าตา และ JavaScript เพื่อเพิ่มความสามารถในการโต้ตอบกับผู้ใช้

## วิวัฒนาการของ HTML

วิวัฒนาการของ HTML สามารถแบ่งออกเป็นยุคต่างๆ ได้ดังนี้:

1. **ยุคแรกเริ่ม (1991-1995):** HTML เวอร์ชันแรกๆ (HTML 1.0 ถึง HTML 2.0) มีแท็กที่จำกัดและเน้นการแสดงเนื้อหาเป็นหลัก ยังไม่มีการรองรับการจัดรูปแบบที่ซับซ้อนหรือการโต้ตอบกับผู้ใช้
2. **ยุคของการจัดรูปแบบ (1995-1999):** HTML 3.2 และ HTML 4.0 ได้รับการพัฒนาขึ้นในยุคนี้ โดยมีการเพิ่มแท็กและคุณสมบัติใหม่ๆ ที่ช่วยให้สามารถจัดรูปแบบเว็บเพจได้หลากหลายขึ้น เช่น การใช้ตาราง (table) ในการจัดวางองค์ประกอบ การใช้เฟรม (frame) ในการแบ่งหน้าจอ และการใช้ฟอร์ม (form) ในการรับข้อมูลจากผู้ใช้
3. **ยุคของเว็บมาตรฐาน (2000-2014):** ในยุคนี้ W3C (World Wide Web Consortium) ได้เข้ามามีบทบาทสำคัญในการกำหนดมาตรฐานของ HTML โดยได้ออก HTML 4.01 ซึ่งเป็นเวอร์ชันที่ได้รับความนิยมอย่างแพร่หลาย และ XHTML 1.0 ซึ่งเป็นเวอร์ชันที่ใช้ XML ในการกำหนดโครงสร้างของ HTML
4. **ยุคของ HTML5 (2014-ปัจจุบัน):** HTML5 เป็นเวอร์ชันล่าสุดของ HTML ที่ได้รับการพัฒนาขึ้นเพื่อรองรับการใช้งานบนอุปกรณ์ที่หลากหลาย เช่น คอมพิวเตอร์ตั้งโต๊ะ, แล็ปท็อป, แท็บเล็ต และสมาร์ทโฟน HTML5 มีการเพิ่มแท็กและคุณสมบัติใหม่ๆ มากมาย เช่น แท็กวิดีโอและเสียง, แท็ก Canvas สำหรับการวาดภาพ, แท็กสำหรับการจัดรูปแบบเนื้อหาแบบ semantic และ API ต่างๆ ที่ช่วยให้สามารถพัฒนาเว็บแอปพลิเคชันที่มีความซับซ้อนและสวยงามได้ง่ายขึ้น

**ในปัจจุบัน HTML5 ยังคงได้รับการพัฒนาและปรับปรุงอย่างต่อเนื่อง** โดยมีการเพิ่มคุณสมบัติใหม่ๆ เข้ามาเรื่อยๆ เพื่อตอบสนองความต้องการของผู้ใช้งานและเทคโนโลยีที่เปลี่ยนแปลงไป

## โครงสร้างของแท็ก HTML

1. **แท็กเปิด (Opening Tag):**
    - เริ่มต้นด้วยเครื่องหมายน้อยกว่า `<`
    - ตามด้วยชื่อแท็ก (tag name) เช่น `html`, `head`, `body`, `p`, `div`
    - อาจมีแอตทริบิวต์ (attribute) ซึ่งเป็นคู่ของชื่อแอตทริบิวต์และค่า โดยคั่นด้วยเครื่องหมายเท่ากับ `=` และใส่ค่าในเครื่องหมายคำพูด `""`
    - สิ้นสุดด้วยเครื่องหมายมากกว่า `>`
    - ตัวอย่าง: `<p id="myParagraph" class="highlight">`
2. **เนื้อหา (Content):**
    - ข้อมูลที่อยู่ระหว่างแท็กเปิดและแท็กปิด อาจเป็นข้อความ รูปภาพ หรือแท็ก HTML อื่น ๆ
    - ตัวอย่าง: `<p>นี่คือย่อหน้าตัวอย่าง</p>`
3. **แท็กปิด (Closing Tag):**
    - เริ่มต้นด้วยเครื่องหมายน้อยกว่าและเครื่องหมายทับ `</`
    - ตามด้วยชื่อแท็กเดียวกับแท็กเปิด
    - สิ้นสุดด้วยเครื่องหมายมากกว่า `>`
    - ตัวอย่าง: `</p>`
