# HTML with CSS

HTML (Hypertext Markup Language) และ CSS (Cascading Style Sheets) เป็นสองเทคโนโลยีหลักที่ทำงานร่วมกันเพื่อสร้างและออกแบบเว็บเพจที่เราเห็นบนอินเทอร์เน็ต

**HTML:**

- **โครงสร้าง:** HTML ทำหน้าที่เป็นโครงสร้างหลักของเว็บเพจ เปรียบเสมือนโครงกระดูกของบ้าน โดยใช้แท็ก (tags) ต่างๆ เพื่อกำหนดองค์ประกอบต่างๆ ของหน้าเว็บ เช่น หัวข้อ (headings), ย่อหน้า (paragraphs), รูปภาพ (images), ลิงก์ (links) เป็นต้น
- **เนื้อหา:** นอกจากโครงสร้างแล้ว HTML ยังใช้สำหรับใส่เนื้อหาต่างๆ ลงในเว็บเพจ เช่น ข้อความ รูปภาพ หรือวิดีโอ

```html
<h1>นี่คือหัวข้อ</h1>
<p>นี่คือย่อหน้า</p>
<img src="image.jpg" alt="รูปภาพ">
```

**CSS:**

- **การตกแต่ง:** CSS ทำหน้าที่ตกแต่งและจัดรูปแบบองค์ประกอบต่างๆ ที่กำหนดไว้ใน HTML เปรียบเสมือนการตกแต่งภายในและภายนอกของบ้าน ทำให้เว็บเพจดูสวยงามและน่าสนใจ
- **รูปแบบ:** CSS สามารถกำหนดรูปแบบต่างๆ ได้หลากหลาย เช่น สี ขนาด ฟอนต์ ตำแหน่ง การจัดวาง และอื่นๆ อีกมากมาย

```css
h1 {
  color: blue; /* กำหนดสีตัวอักษรของหัวข้อเป็นสีน้ำเงิน */
  font-size: 24px; /* กำหนดขนาดตัวอักษรของหัวข้อเป็น 24 พิกเซล */
}

p {
  text-align: justify; /* จัดรูปแบบย่อหน้าให้ชิดขอบทั้งสองด้าน */
}
```

CSS สามารถนำมาตกแต่ง HTML ได้หลากหลายวิธี ซึ่งแต่ละวิธีก็มีข้อดีและข้อจำกัดที่แตกต่างกันไป ขึ้นอยู่กับความเหมาะสมในการใช้งาน

**1. Inline CSS:**

- **วิธีการ:** เขียน CSS ไว้ในแอตทริบิวต์ `style` ของแท็ก HTML โดยตรง

```html
 <p style="color: red; font-size: 16px;">นี่คือย่อหน้าสีแดง</p>
```

- **ข้อดี:** ใช้งานง่ายและรวดเร็ว เหมาะสำหรับการปรับแต่งเล็กๆ น้อยๆ
- **ข้อจำกัด:** ยากต่อการจัดการเมื่อมีโค้ด CSS จำนวนมาก ทำให้โค้ดยาวและอ่านยาก

**2. Internal CSS (Embedded CSS):**

- **วิธีการ:** เขียน CSS ไว้ภายในแท็ก `<style>` ในส่วน `<head>` ของ HTML

```html
<head>
  <style>
    p {
      color: blue;
      font-size: 14px;
    }
  </style>
</head>
```

- **ข้อดี:** สามารถนำ CSS ไปใช้กับหลายๆ องค์ประกอบในหน้าเว็บเดียวกันได้ ทำให้โค้ดเป็นระเบียบมากขึ้น
- **ข้อจำกัด:** ยังไม่เหมาะกับเว็บไซต์ขนาดใหญ่ที่มีหลายหน้า เพราะต้องคัดลอกโค้ด CSS ไปวางในทุกๆ หน้า

**3. External CSS:**

- **วิธีการ:** เขียน CSS ไว้ในไฟล์แยกต่างหาก (นามสกุล `.css`) แล้วเชื่อมโยงไฟล์นั้นกับ HTML ด้วยแท็ก `<link>`

```html
<head>
  <link rel="stylesheet" href="style.css" />
</head>
```

- **ข้อดี:** เหมาะสำหรับเว็บไซต์ขนาดใหญ่ สามารถนำ CSS ไฟล์เดียวไปใช้กับหลายๆ หน้าได้ ทำให้โค้ดเป็นระเบียบและง่ายต่อการจัดการ
- **ข้อจำกัด:** ต้องสร้างไฟล์ CSS แยกต่างหาก อาจทำให้โหลดหน้าเว็บช้าลงเล็กน้อย

นอกจากนี้ CSS ยังมีวิธีการเลือก (Selector) ที่หลากหลาย เพื่อนำไปใช้กับองค์ประกอบต่างๆ ใน HTML:

- **Element Selector:** เลือกองค์ประกอบตามชื่อแท็ก เช่น `p`, `h1`, `div`
- **ID Selector:** เลือกองค์ประกอบตาม ID ที่กำหนดไว้ เช่น `#header`, `#footer`
- **Class Selector:** เลือกองค์ประกอบตามคลาสที่กำหนดไว้ เช่น `.highlight`, `.button`
- **Attribute Selector:** เลือกองค์ประกอบตามแอตทริบิวต์ เช่น `input[type="text"]`
- **Pseudo-class Selector:** เลือกองค์ประกอบตามสถานะ เช่น `:hover`, `:active`
- **Pseudo-element Selector:** เลือกส่วนประกอบย่อยขององค์ประกอบ เช่น `::before`, `::after`

```css
CSS
/* Element Selector */
p {
  color: gray;
}

/* ID Selector */
#main-content {
  background-color: lightblue;
}

/* Class Selector */
.important-text {
  font-weight: bold;
}
```

การเลือกวิธีการตกแต่ง HTML ด้วย CSS ที่เหมาะสมนั้นขึ้นอยู่กับขนาดและความซับซ้อนของเว็บไซต์ รวมถึงความถนัดของผู้พัฒนา หากเป็นเว็บไซต์ขนาดเล็ก อาจเลือกใช้ Inline CSS หรือ Internal CSS แต่หากเป็นเว็บไซต์ขนาดใหญ่ ควรเลือกใช้ External CSS เพื่อให้ง่ายต่อการจัดการและบำรุงรักษาโค้ด
