# JavaScript Event

JavaScript Event คือการกระทำหรือเหตุการณ์ที่เกิดขึ้นในหน้าเว็บหรือแอปพลิเคชัน เช่น การคลิกเมาส์ การกดแป้นพิมพ์ หรือการโหลดหน้าเว็บการทำงาน: 

- Event Occurs: เหตุการณ์เกิดขึ้น
- Event Detected: JavaScript ตรวจจับเหตุการณ์
- Event Handler Executes: โค้ด JavaScript ที่กำหนดไว้สำหรับจัดการเหตุการณ์นั้นจะทำงาน

ตัวอย่าง:

```jsx
button.addEventListener("click", function () {
  alert("ปุ่มถูกคลิก!");
});
```

ในตัวอย่างนี้ เมื่อปุ่มถูกคลิก ฟังก์ชันที่กำหนดไว้จะทำงานและแสดงข้อความ "ปุ่มถูกคลิก!”
