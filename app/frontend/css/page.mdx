# CSS

## CSS คืออะไร

CSS หรือ Cascading Style Sheets คือ ภาษาที่ใช้ในการตกแต่งรูปแบบและลักษณะของเว็บเพจ โดยจะทำงานร่วมกับ HTML ซึ่งเป็นภาษาที่ใช้ในการสร้างโครงสร้างของเว็บเพจ CSS ช่วยให้คุณสามารถกำหนดสี, ขนาดตัวอักษร, รูปแบบตัวอักษร, ระยะขอบ, การจัดวางองค์ประกอบต่างๆ และอื่นๆ อีกมากมาย เพื่อให้เว็บเพจของคุณดูสวยงามและน่าสนใจ

## **CSS ทำงานอย่างไร**

CSS ทำงานโดยการเลือกองค์ประกอบ HTML ที่คุณต้องการตกแต่ง แล้วกำหนดรูปแบบที่คุณต้องการให้กับองค์ประกอบนั้นๆ คุณสามารถเลือกองค์ประกอบ HTML ได้หลายวิธี เช่น การเลือกตามชื่อแท็ก (tag), การเลือกตามคลาส (class), การเลือกตามไอดี (ID) เป็นต้น

```css
body {
  font-family: Arial, sans-serif;
  background-color: #f4f4f4;
  color: #333;
}

h1 {
  color: #007bff;
}
```

## **ความสำคัญของ CSS**

CSS มีความสำคัญอย่างมากในการสร้างเว็บไซต์ที่สวยงามและน่าใช้งาน CSS ช่วยให้คุณสามารถแยกการออกแบบออกจากเนื้อหา ทำให้การจัดการเว็บไซต์ของคุณง่ายขึ้น และยังช่วยให้เว็บไซต์ของคุณสามารถปรับตัวให้เข้ากับอุปกรณ์ต่างๆ ได้ดีขึ้น

## ผู้ให้กําเนิด

ผู้ให้กําเนิด CSS คือ Håkon Wium Lie นักวิทยาศาสตร์คอมพิวเตอร์ชาวนอร์เวย์ โดยเขาได้เสนอแนวคิด CSS ในปี ค.ศ. 1994 ขณะที่ทำงานอยู่ที่ CERN (องค์กรวิจัยนิวเคลียร์ยุโรป) เช่นเดียวกับ Tim Berners-Lee ผู้สร้าง HTML

![Untitled](/images/classroom/frontend/css/untitled.png)

Håkon Wium Lie ได้พัฒนา CSS ร่วมกับ Bert Bos โดยมีจุดประสงค์เพื่อแยกการออกแบบ (style) ออกจากเนื้อหา (content) ของเว็บเพจ ซึ่งจะช่วยให้การจัดการเว็บไซต์ง่ายขึ้น และสามารถนำ style เดียวกันไปใช้กับหลายๆ หน้าเว็บได้

CSS เวอร์ชันแรก (CSS1) ได้รับการรับรองโดย W3C (World Wide Web Consortium) ในปี ค.ศ. 1996 และต่อมาได้มีการพัฒนา CSS เวอร์ชันใหม่ๆ ออกมาอย่างต่อเนื่อง เช่น CSS2, CSS3 และ CSS4 ซึ่งแต่ละเวอร์ชันจะมีการเพิ่มคุณสมบัติและความสามารถใหม่ๆ เข้ามา เพื่อให้สามารถตกแต่งเว็บเพจได้อย่างหลากหลายและสวยงามมากยิ่งขึ้น

โครงสร้างของ CSS (Cascading Style Sheets) ประกอบด้วย 2 ส่วนหลัก คือ:

1. **ตัวเลือก (Selector):**
    - ใช้ระบุว่าจะนำสไตล์ไปปรับใช้กับองค์ประกอบ HTML ใด
    - สามารถเลือกได้หลายวิธี เช่น
        - เลือกตามชื่อแท็ก (element selector): เช่น `p`, `h1`, `div`
        - เลือกตามคลาส (class selector): เริ่มต้นด้วยจุด `.` ตามด้วยชื่อคลาส เช่น `.highlight`
        - เลือกตามไอดี (ID selector): เริ่มต้นด้วยเครื่องหมาย # ตามด้วยชื่อไอดี เช่น `#myParagraph`
        - เลือกแบบอื่นๆ เช่น เลือกตามแอตทริบิวต์ (attribute selector), เลือกตามสถานะ (pseudo-class selector)
2. **ส่วนประกาศ (Declaration):**
    - กำหนดคุณสมบัติ (property) และค่า (value) ของสไตล์ที่ต้องการปรับใช้
    - รูปแบบ: `property: value;`
    - ตัวอย่าง: `color: red;`, `font-size: 16px;`, `background-color: #f0f0f0;`

ตัวอย่างโครงสร้าง

```css
selector {
  property1: value1;
  property2: value2;
  property3: value3;
  /* ... */
}
```

ตัวอย่างการใช้งาน

```css
p { /* เลือกทุกย่อหน้า */
  color: blue;
  font-size: 14px;
}

.highlight { /* เลือกองค์ประกอบที่มี class="highlight" */
  background-color: yellow;
}

#myParagraph { /* เลือกองค์ประกอบที่มี id="myParagraph" */
  font-weight: bold;
}
```
