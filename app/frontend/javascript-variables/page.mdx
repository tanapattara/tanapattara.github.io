# JavaScript Variable

ภาษา JavaScript ไม่มีการประกาศชนิดของตัวแปร (Data type) เราสามารถนำค่าอะไรมาใส่ในตัวแปรก็ได้ โปรแกรมสามารถบันทึกหรือจัดเก็บข้อมูลได้หมด ซึ่งเป็นทั้งข้อดีและข้อเสียในการพัฒนาโปรแกรม

## ตัวแปรและการตั้งชื่อตัวแปร ในภาษา JavaScript

- ขึ้นต้นด้วยตัวอักษร, $, หรือ _
- ตามด้วยตัวอักษร, ตัวเลข, $, หรือ _
- Case-sensitive: myVar ต่างจาก myvar
- ไม่ใช้คำสงวน: เช่น if, else, for
- ควรมีความหมาย: บอกว่าตัวแปรเก็บข้อมูลอะไร
- ใช้ camelCase: เช่น firstName, numberOfItems

ตัวอย่าง:

```jsx
let message = "สวัสดี!";
const PI = 3.14159;
let $special = true;
```

## การประกาศตัวแปร

## let:

- ใช้เมื่อต้องการประกาศตัวแปรที่สามารถเปลี่ยนแปลงค่าได้ในภายหลัง
- มีขอบเขตจำกัดเฉพาะบล็อก (block scope) ที่ประกาศ
- ไม่สามารถประกาศซ้ำในขอบเขตเดียวกันได้

ตัวอย่าง:

```jsx
let x = 10;
if (true) {
  let x = 20; // x ในนี้มีค่า 20
}
console.log(x); // x นอกบล็อกยังคงมีค่า 10
```

## const:

- ใช้เมื่อต้องการประกาศตัวแปรที่มีค่าคงที่ ไม่สามารถเปลี่ยนแปลงได้
- มีขอบเขตจำกัดเฉพาะบล็อก (block scope) ที่ประกาศ
- ไม่สามารถประกาศซ้ำในขอบเขตเดียวกันได้

ตัวอย่าง:

```jsx
const PI = 3.14159;
PI = 3; // จะเกิดข้อผิดพลาด
```

## var:

- ใช้น้อยลงในปัจจุบัน เนื่องจากมีข้อจำกัดเรื่องขอบเขต (function scope)
- สามารถประกาศซ้ำในขอบเขตเดียวกันได้

ตัวอย่าง:

```jsx
var y = 5;
var y = 10; // ไม่มีข้อผิดพลาด แต่ไม่ควรทำ
```

> **หมายเหตุ**
> ⚠️ กรณีที่มีการประกาศตัวแปรโดยใช้คำสั่ง `var` เมื่อมีการประกาศอีกครั้งโดยที่ใช้ชื่อเดิม โปรแกรมจะไม่แจ้งเตือนข้อผิดพลาด ว่ามีการประกาศชื่อตัวแปรซ้ำ ทำให้อาจเกิดปัญหาการใช้ตัวแปรร่วมกัน บันทึกข้อมูลผิดพลาดได้
>
