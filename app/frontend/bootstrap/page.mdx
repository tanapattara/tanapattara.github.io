# Bootstrap CSS

Bootstrap CSS คือเฟรมเวิร์ก CSS ยอดนิยมที่ช่วยให้คุณสร้างเว็บไซต์ที่สวยงามและตอบสนองต่ออุปกรณ์ต่างๆ ได้ง่ายและรวดเร็ว โดยไม่ต้องเขียน CSS ขึ้นมาเองทั้งหมด Bootstrap มาพร้อมกับคลาส CSS ที่กำหนดไว้ล่วงหน้ามากมาย, องค์ประกอบ UI ที่หลากหลาย

Bootstrap ถูกสร้างขึ้นครั้งแรกโดย Mark Otto และ Jacob Thornton ที่บริษัท Twitter ในปี 2010 เดิมทีมันถูกพัฒนาขึ้นเพื่อใช้เป็นเครื่องมือภายในของ Twitter แต่ต่อมาได้ถูกเปิดให้ใช้งานเป็นโอเพ่นซอร์สในปี 2011 ปัจจุบัน Bootstrap ได้รับการดูแลและพัฒนาโดยทีมงานหลักและชุมชนผู้ใช้งานทั่วโลก

## **การเริ่มต้นใช้งาน:**

Bootstrap จะทำการเตรียมไฟล์ css หรือ js ที่ต้องใช้งานให้เรา โดยเราสามารถเรียกใช้งานได้สองวิธี และทำการเรียกใช้งานผ่าน HTML ในแท็ก `<head>`

- **ดาวน์โหลด:** ดาวน์โหลด Bootstrap จากเว็บไซต์ทางการ ([https://getbootstrap.com/](https://getbootstrap.com/)) แล้วทำการเรียกใช้งานผ่านการไฟล์ที่ดาวน์โหลด ตามตำแหน่งที่ติดตั้งใจโปรแจค
- **ใช้ CDN (Content Delivery Network) เชื่อมต่อไฟล์:** เพิ่มไฟล์ CSS และ JavaScript ของ Bootstrap ในส่วน `<head>` ของ HTML:

```html
<head>
  <link
    rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"
  />
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</head>
```

## **ระบบ Grid:**

ข้อดีอีกอย่างหนึ่งของ CSS Framework คือการมีระบบ Grid ให้เราใช้งาน ระบบนี้จะแบ่งหน้าของเราออกเป็น 12 column ทำให้เราแบ่งส่วนที่เราต้องการได้ตามการใช้งาน

- Bootstrap ใช้ระบบ grid 12 คอลัมน์เพื่อจัดวางเลย์เอาต์ของเนื้อหา
- ใช้คลาส `.container`, `.row`, และ `.col-*` เพื่อสร้างโครงสร้าง grid

```html
<div class="container">
  <div class="row">
    <div class="col-md-6">เนื้อหาคอลัมน์ที่ 1</div>
    <div class="col-md-6">เนื้อหาคอลัมน์ที่ 2</div>
  </div>
</div>
```

ตัวอย่างข้างบนคือการแบ่ง column ออกเป็นสองส่วนเท่า ๆ กัน คือ 6 : 6 หากต้องการปรับให้ด้านซ้ายมีขนาดเล็กลง เราอาจจะปรับเป็น 4:8 ทำให้คอลัมน์ด้านซ้ายเล็กลงมีขนาด 4 ส่วน ด้านขวาใหญ่ขึ้นมีขนาด 8 ส่วน โดยทั้งสองส่วนยังรวมกันเท่ากับ 12 หรือหนึ่งหน้าของระบบ Grid นั่นเอง

```html
<div class="container">
  <div class="row">
    <div class="col-md-4">เนื้อหาคอลัมน์ที่ 1</div>
    <div class="col-md-8">เนื้อหาคอลัมน์ที่ 2</div>
  </div>
</div>
```

การกำหนดขนาดคอลัมน์ตามขนาดหน้าจอ

Bootstrap ได้ทำการเตรียมคลาสสำหรับขนาดหน้าจอต่าง ๆ ไว้ 6 ขนาดด้วยกัน แต่ที่เรานิยมใช้กันมากมีสามขนาด ขนาดเล็ก กลาง และใหญ่ เพื่อเทียบเท่ากับขนาดของอุปกรณ์ มือถือ แท็บเล็ด และคอมพิวเตอร์ตามลำดับ

| ประเภทอุปกรณ์ | ขนาดตามพิกเซล | พรีฟิกซ์ | ตัวอย่างคลาส |
| --- | --- | --- | --- |
| มือถือ | ≥576px | **sm** | .col-sm-6 |
| แท็บเล็ด | ≥768px | **md** | .col-md-6 |
| คอมพิวเตอร์ | ≥992px | **lg** | .col-lg-6 |

ตัวอย่างการกำหนดตามขนาดของอุปกรณ์

```html
<div class="container">
  <div class="row">
    <div class="col-md-6 col-lg-3">เนื้อหาคอลัมน์ที่ 1</div>
    <div class="col-md-6 col-lg-3">เนื้อหาคอลัมน์ที่ 2</div>
    <div class="col-md-6 col-lg-3">เนื้อหาคอลัมน์ที่ 3</div>
    <div class="col-md-6 col-lg-3">เนื้อหาคอลัมน์ที่ 4</div>
  </div>
</div>
```

ตัวอย่างข้างบน คือ การกำหนดขนาด สองหน้าจออุปกรณ์

- หากเป็นแท็บเล็ก จะแบ่งออกเป็น 2 คอลัมน์
- หากเป็นคอมพิวเตอร์ จะถูกแบ่งออกเป็น 4 คอลัมน์

## **องค์ประกอบ UI:**

- 
- Bootstrap มีองค์ประกอบ UI ที่หลากหลาย เช่น ปุ่ม, แบบฟอร์ม, การแจ้งเตือน, การนำทาง, และอื่นๆ
- ใช้คลาสที่กำหนดไว้ล่วงหน้าเพื่อปรับแต่งองค์ประกอบเหล่านี้

```html
<button class="btn btn-primary">ปุ่ม</button>
<div class="alert alert-success">การแจ้งเตือน</div>
```

## JavaScript plugins:

- Bootstrap มาพร้อมกับ JavaScript plugins ที่มีประโยชน์ เช่น modals, tooltips, carousels, และอื่นๆ
- ใช้ data attributes หรือ JavaScript เพื่อเปิดใช้งาน plugins เหล่านี้

```html
<button
  type="button"
  class="btn btn-primary"
  data-bs-toggle="modal"
  data-bs-target="#myModal"
>
  เปิด Modal
</button>
```

## **ข้อดีของการใช้ Bootstrap CSS:**

- **ประหยัดเวลา:** ไม่ต้องเขียน CSS ตั้งแต่เริ่มต้น
- **ตอบสนองต่ออุปกรณ์ต่างๆ:** เว็บไซต์ที่สร้างด้วย Bootstrap จะปรับขนาดให้เหมาะสมกับอุปกรณ์ต่างๆ โดยอัตโนมัติ
- **ใช้งานง่าย:** คลาส CSS และองค์ประกอบ UI ของ Bootstrap ใช้งานง่าย
- **ชุมชนขนาดใหญ่:** มีชุมชนผู้ใช้งาน Bootstrap ขนาดใหญ่ที่คอยช่วยเหลือและแบ่งปันความรู้
