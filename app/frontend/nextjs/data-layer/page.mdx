# Data Layer และข้อมูลตัวอย่าง

Next.js ไม่ได้มีฐานข้อมูลในตัว ตัวอย่างบทถัดไปจึงต้องมี Data Layer ที่กำหนดวิธีอ่านและแก้ข้อมูลให้ชัดเจน บทนี้สร้าง Repository แบบ in-memory สำหรับทดลองบน Development Server ก่อน แล้วจึงค่อยเปลี่ยน implementation เป็นฐานข้อมูลจริงโดยไม่ต้องเปลี่ยน Component หรือ Route Handler ทุกจุด

> Repository ในบทนี้มีไว้เพื่อการเรียนเท่านั้น ข้อมูลอยู่ในหน่วยความจำของ Node.js และอาจหายเมื่อ restart, rebuild หรือเปลี่ยน server instance ห้ามใช้เก็บข้อมูลจริงใน production

## สร้าง Book Repository

สร้าง `lib/books.ts` และป้องกันไม่ให้ Client Component import ไฟล์นี้ด้วย `server-only`

```tsx
// lib/books.ts
import 'server-only'
import { randomUUID } from 'node:crypto'

export type Book = {
  id: string
  title: string
  price: number
  summary: string
  coverUrl: string
  isFavorite: boolean
}

export type BookInput = Pick<Book, 'title' | 'price'> &
  Partial<Pick<Book, 'summary' | 'coverUrl'>>

const initialBooks: Book[] = [
  {
    id: '101',
    title: 'เรียนรู้ Next.js',
    price: 490,
    summary: 'พื้นฐาน App Router และ Server Components',
    coverUrl: '/images/nextjs-book.jpg',
    isFavorite: false,
  },
  {
    id: '102',
    title: 'TypeScript สำหรับเว็บ',
    price: 420,
    summary: 'สร้างเว็บด้วย TypeScript อย่างเป็นระบบ',
    coverUrl: '/images/typescript-book.jpg',
    isFavorite: true,
  },
]

const globalForBooks = globalThis as typeof globalThis & {
  demoBooks?: Map<string, Book>
}

const books =
  globalForBooks.demoBooks ??
  new Map(initialBooks.map((book) => [book.id, book]))

if (process.env.NODE_ENV !== 'production') {
  globalForBooks.demoBooks = books
}

export async function listBooks(query = ''): Promise<Book[]> {
  const normalizedQuery = query.trim().toLocaleLowerCase('th-TH')
  return [...books.values()].filter((book) =>
    book.title.toLocaleLowerCase('th-TH').includes(normalizedQuery),
  )
}

export async function getBook(id: string): Promise<Book | null> {
  return books.get(id) ?? null
}

export async function insertBook(input: BookInput): Promise<Book> {
  const book: Book = {
    id: randomUUID(),
    title: input.title,
    price: input.price,
    summary: input.summary ?? '',
    coverUrl: input.coverUrl ?? '/images/book-placeholder.jpg',
    isFavorite: false,
  }

  books.set(book.id, book)
  return book
}

export async function updateBook(
  id: string,
  input: Partial<BookInput>,
): Promise<Book | null> {
  const current = books.get(id)
  if (!current) return null

  const updated = { ...current, ...input, id }
  books.set(id, updated)
  return updated
}

export async function removeBook(id: string): Promise<boolean> {
  return books.delete(id)
}
```

การเก็บ Map ไว้ใน `globalThis` ช่วยลดการสร้างข้อมูลใหม่ระหว่าง Hot Reload แต่ไม่ได้ทำให้ข้อมูลคงอยู่ถาวร และไม่ได้ทำให้หลาย server instance ใช้ข้อมูลชุดเดียวกัน

## เรียกผ่าน Data Layer

Server Component เรียก Repository โดยตรงได้ ไม่ต้อง fetch Route Handler ของแอปตัวเอง

```tsx
// app/books/page.tsx
import { listBooks } from '@/lib/books'

export default async function BooksPage() {
  const books = await listBooks()

  return (
    <ul>
      {books.map((book) => (
        <li key={book.id}>{book.title}</li>
      ))}
    </ul>
  )
}
```

## เปลี่ยนเป็นฐานข้อมูลจริง

เมื่อเริ่มใช้ฐานข้อมูล ให้คงชื่อ function เช่น `listBooks`, `getBook`, `insertBook` และ `removeBook` ไว้ แล้วเปลี่ยนเฉพาะ implementation ภายใน `lib/books.ts` เป็น ORM, SQL client หรือ SDK ของบริการฐานข้อมูล วิธีนี้ทำให้กฎ validation และ authorization อยู่ใกล้ข้อมูล และลดการผูก UI เข้ากับ library ใด library หนึ่ง

หลักที่ต้องรักษาเมื่อเปลี่ยนเป็นฐานข้อมูลจริง:

- สร้าง connection/client นอก request handler และ reuse ตามคำแนะนำของ driver
- กำหนด unique constraint และ foreign key ในฐานข้อมูล ไม่พึ่งการตรวจด้วย JavaScript อย่างเดียว
- เลือกคืนเฉพาะ field ที่ UI ต้องใช้
- ใช้ transaction เมื่อต้องแก้หลายตารางให้สำเร็จหรือยกเลิกพร้อมกัน
- ใช้ฐานข้อมูลหรือ persistent service จริงเมื่อ deploy แบบหลาย instance หรือ serverless

## แบบฝึกหัด

1. เพิ่มหนังสือเล่มที่สามใน `initialBooks`
2. สร้างหน้า `/books` ที่เรียก `listBooks()`
3. สร้างหน้า `/books/[id]` ที่เรียก `getBook(id)` และจัดการกรณีไม่พบข้อมูล
4. restart Development Server แล้วสังเกตว่าข้อมูลที่เพิ่มระหว่าง runtime ไม่ใช่ข้อมูลถาวร
