# การพัฒนาเว็บด้วย Next.js

Next.js คือ React framework สำหรับสร้างเว็บแอปพลิเคชันที่มีทั้งส่วนแสดงผลและความสามารถฝั่งเซิร์ฟเวอร์อยู่ในโครงการเดียวกัน หลักสูตรส่วนนี้ใช้ **App Router**, TypeScript และแนวคิด Server Components ซึ่งเป็นรูปแบบหลักของ Next.js รุ่นปัจจุบัน

เมื่อเรียนครบ ผู้เรียนจะสามารถสร้างเส้นทางและ Layout ดึงและแก้ไขข้อมูล สร้าง API จัดการสถานะ Loading/Error เพิ่ม SEO และเลือกรูปแบบ Deployment ให้เหมาะกับงานได้

> **พื้นฐานที่ควรมีก่อนเรียน:** HTML, CSS, JavaScript, React Component, Props, State, Event และ `async`/`await`

## หมายเหตุเกี่ยวกับเว็บไซต์รายวิชา

เว็บไซต์เอกสารนี้ใช้ `output: "export"` เพื่อเผยแพร่บน GitHub Pages จึงไม่มี Next.js server ขณะใช้งานจริง ตัวอย่าง Route Handlers, Server Actions และ Authentication ต้องทดลองในโปรเจกต์ Next.js แยกที่ deploy แบบ Node.js หรือ Vercel รายละเอียดอยู่ในบท Build และ Deployment
