# Server Components และ Client Components

หน้าและ Layout ใน App Router เป็น **Server Components โดยค่าเริ่มต้น** โค้ดจึงทำงานบน Server และส่งผลลัพธ์ที่จำเป็นมายัง Browser ส่วน Client Components ใช้เมื่อ UI ต้องตอบสนองต่อ Event, ใช้ React Hook หรือเรียก Browser API

## เลือก Component ให้ถูกประเภท

| ความต้องการ | Server Component | Client Component |
| --- | --- | --- |
| อ่านฐานข้อมูลหรือ secret | เหมาะสม | ไม่ควร |
| `async`/`await` ที่ระดับ component | รองรับ | ไม่รองรับ |
| `useState`, `useEffect` | ไม่รองรับ | รองรับ |
| `onClick`, `onChange` | ไม่รองรับ | รองรับ |
| `window`, `localStorage` | ไม่รองรับ | รองรับ |
| ลด JavaScript ที่ส่งไป Browser | ทำได้ดี | ส่ง JavaScript เพิ่ม |

หลักง่าย ๆ คือเริ่มด้วย Server Component แล้วเพิ่ม `'use client'` เฉพาะ component ย่อยที่ต้อง interactive

## ตัวอย่าง Server Component

```tsx
// app/books/page.tsx
import { db } from '@/lib/db'

export default async function BooksPage() {
  const books = await db.book.findMany()

  return (
    <ul>
      {books.map((book) => (
        <li key={book.id}>{book.title}</li>
      ))}
    </ul>
  )
}
```

ตัวอย่างนี้เข้าถึงฐานข้อมูลโดยตรง ไม่ต้องสร้าง API ภายในแล้วให้ Server เรียกกลับหาตัวเอง และ connection string ไม่ถูกส่งไป Browser

## ตัวอย่าง Client Component

```tsx
// components/quantity-picker.tsx
'use client'

import { useState } from 'react'

export function QuantityPicker() {
  const [quantity, setQuantity] = useState(1)

  return (
    <div>
      <button onClick={() => setQuantity((value) => Math.max(1, value - 1))}>
        ลด
      </button>
      <span>{quantity}</span>
      <button onClick={() => setQuantity((value) => value + 1)}>เพิ่ม</button>
    </div>
  )
}
```

`'use client'` กำหนดขอบเขตระหว่าง Server และ Client ไฟล์ที่ component นี้ import ต่อจะอยู่ใน Client bundle ด้วย จึงไม่ควรใส่ directive นี้ไว้สูงเกินความจำเป็น

## การประกอบ Server และ Client เข้าด้วยกัน

Server Component ดึงข้อมูล แล้วส่งข้อมูลธรรมดาให้ Client Component จัดการ Event

```tsx
// app/books/[id]/page.tsx
import { FavoriteButton } from '@/components/favorite-button'
import { getBook } from '@/lib/books'

type Props = { params: Promise<{ id: string }> }

export default async function BookPage({ params }: Props) {
  const { id } = await params
  const book = await getBook(id)

  return (
    <article>
      <h1>{book.title}</h1>
      <FavoriteButton bookId={book.id} initialValue={book.isFavorite} />
    </article>
  )
}
```

```tsx
// components/favorite-button.tsx
'use client'

import { useState } from 'react'

export function FavoriteButton({
  bookId,
  initialValue,
}: {
  bookId: string
  initialValue: boolean
}) {
  const [favorite, setFavorite] = useState(initialValue)

  return (
    <button onClick={() => setFavorite((value) => !value)}>
      {favorite ? 'นำออกจากรายการโปรด' : 'เพิ่มในรายการโปรด'} ({bookId})
    </button>
  )
}
```

## ข้อมูลที่ส่งข้าม Boundary

Props จาก Server ไป Client ต้อง serialize ได้ เช่น string, number, boolean, array และ plain object

```tsx
// ควรแปลง Date เป็น string ก่อนส่ง
<BookInfo publishedAt={book.publishedAt.toISOString()} />
```

ไม่ควรส่ง function ทั่วไป, class instance, `Date`, `Map` หรือ `Set` โดยตรง ข้อยกเว้นคือ Server Action ที่ประกาศด้วย `'use server'`

## ข้อผิดพลาดที่พบบ่อย

```tsx
// ไม่ถูกต้อง: Client Component ห้ามเป็น async component
'use client'

export default async function Profile() {
  const user = await getUser()
  return <p>{user.name}</p>
}
```

ให้ย้ายการดึงข้อมูลไป Server parent แล้วส่งผลผ่าน props หรือดึงจาก API ภายใน `useEffect` เมื่อมีเหตุผลที่ต้องทำฝั่ง Client

Hydration mismatch มักเกิดจาก render `window`, เวลาปัจจุบัน หรือ `Math.random()` ในผลลัพธ์แรก ให้ย้าย Browser API ไป `useEffect` และใช้ `useId()` สำหรับ ID ที่ต้องตรงกัน

## แบบฝึกหัด

สร้างหน้ารายละเอียดหนังสือเป็น Server Component และสร้างปุ่มเพิ่มจำนวนสินค้าเป็น Client Component ตรวจด้วย Browser DevTools ว่า secret และโค้ดฐานข้อมูลไม่ปรากฏใน JavaScript bundle
