# Metadata, SEO และ Asset Optimization

SEO ไม่ได้เกิดจาก keyword เพียงอย่างเดียว หน้าเว็บต้องมีโครงสร้าง HTML ที่ดี โหลดเร็ว ใช้งานบนมือถือได้ และมี Metadata ที่อธิบายเนื้อหา Next.js มี API สำหรับ title, description, social preview, รูปภาพ และ font โดยตรง

## Static Metadata

ประกาศ `metadata` ใน Server Component ที่เป็น `layout.tsx` หรือ `page.tsx`

```tsx
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: 'หนังสือทั้งหมด',
  description: 'ค้นหาและเลือกซื้อหนังสือจากร้าน Book Store',
}

export default function BooksPage() {
  return <h1>หนังสือทั้งหมด</h1>
}
```

กำหนด title template ใน root layout เพื่อให้ชื่อทุกหน้าสม่ำเสมอ

```tsx
export const metadata: Metadata = {
  title: {
    default: 'Book Store',
    template: '%s | Book Store',
  },
  description: 'ร้านหนังสือสำหรับนักพัฒนา',
}
```

หน้า Books ที่กำหนด title ว่า `หนังสือทั้งหมด` จะได้ `<title>หนังสือทั้งหมด | Book Store</title>`

## Dynamic Metadata

```tsx
import type { Metadata } from 'next'
import { notFound } from 'next/navigation'
import { getBook } from '@/lib/books'

type Props = { params: Promise<{ id: string }> }

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { id } = await params
  const book = await getBook(id)

  if (!book) return { title: 'ไม่พบหนังสือ' }

  return {
    title: book.title,
    description: book.summary,
    openGraph: {
      title: book.title,
      description: book.summary,
      images: [book.coverUrl],
    },
  }
}

export default async function BookPage({ params }: Props) {
  const { id } = await params
  const book = await getBook(id)
  if (!book) notFound()

  return <h1>{book.title}</h1>
}
```

ถ้า `generateMetadata` และ Page อ่านข้อมูลเดียวกัน ให้ memoize data function ด้วย React `cache()` เพื่อลด query ซ้ำภายใน request เดียว

## Metadata Files

```text
app/
├── favicon.ico
├── icon.png
├── opengraph-image.png
├── robots.ts
├── sitemap.ts
└── manifest.ts
```

ตัวอย่าง `sitemap.ts`

```tsx
import type { MetadataRoute } from 'next'

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: 'https://book-store.example.com',
      lastModified: new Date(),
      changeFrequency: 'weekly',
      priority: 1,
    },
    {
      url: 'https://book-store.example.com/books',
      lastModified: new Date(),
      changeFrequency: 'daily',
      priority: 0.8,
    },
  ]
}
```

## รูปภาพด้วย next/image

`Image` ช่วยกำหนดขนาดล่วงหน้าเพื่อลด Layout Shift และเลือกขนาดที่เหมาะกับหน้าจอ

```tsx
import Image from 'next/image'

export function BookCover() {
  return (
    <Image
      src="/images/clean-code.jpg"
      alt="ปกหนังสือ Clean Code"
      width={480}
      height={640}
      sizes="240px"
      style={{ width: 240, height: 'auto' }}
    />
  )
}
```

ค่า `sizes` ต้องตรงกับขนาดที่รูปแสดงจริง มิฉะนั้น Browser อาจเลือกรูปเล็กเกินไปหรือดาวน์โหลดไฟล์ใหญ่เกินจำเป็น เมื่อใช้ `fill` parent ต้องมี position และขนาด พร้อมกำหนด `sizes`

```tsx
<div style={{ position: 'relative', width: '100%', aspectRatio: '16 / 9' }}>
  <Image
    src="/images/hero.jpg"
    alt="ชั้นหนังสือภายในร้าน"
    fill
    sizes="100vw"
    style={{ objectFit: 'cover' }}
    preload
  />
</div>
```

ใช้ `preload` เฉพาะรูปสำคัญที่ปรากฏเหนือ fold ไม่ควรใส่กับรูปทุกใบ รูปจาก remote host ต้องกำหนด `images.remotePatterns` ใน `next.config.ts`

## Font ด้วย next/font

```tsx
// app/layout.tsx
import { Noto_Sans_Thai } from 'next/font/google'

const notoSansThai = Noto_Sans_Thai({
  subsets: ['thai'],
  variable: '--font-sans-thai',
  display: 'swap',
})

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="th" className={notoSansThai.variable}>
      <body>{children}</body>
    </html>
  )
}
```

`next/font` ดาวน์โหลดและ self-host font ตอน Build ช่วยลด request ไป Google และลดการขยับของตัวอักษร ไม่ควร import font ซ้ำทุก component

## SEO Checklist

- มี `<h1>` หนึ่งหัวข้อหลักและใช้ heading ตามลำดับ
- รูปมี `alt` ที่บอกความหมาย หรือ `alt=""` หากเป็นรูปตกแต่ง
- ลิงก์มีข้อความที่อธิบายปลายทาง
- title และ description ไม่ซ้ำโดยไม่จำเป็น
- มี canonical URL เมื่อเนื้อหาเดียวเข้าถึงได้หลาย URL
- ตรวจ Core Web Vitals และทดสอบบนมือถือ

## Static Export ของเว็บไซต์รายวิชา

โปรเจกต์นี้ตั้ง `images.unoptimized: true` เพราะ GitHub Pages ไม่มี Image Optimization Server `next/image` ยังช่วยเรื่องขนาดและ layout แต่ไม่ได้แปลงไฟล์แบบ dynamic ควร optimize รูปก่อนใส่ใน `public`

## แบบฝึกหัด

เพิ่ม Metadata ให้หน้ารายการและรายละเอียดหนังสือ สร้าง sitemap ใส่รูปปกด้วย `next/image` และตรวจ `<head>`, alt text, ขนาดรูป และ Layout Shift ด้วย Browser DevTools
