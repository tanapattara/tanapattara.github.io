# Internet

## Internet

อินเทอร์เน็ตทำงานโดยการเชื่อมต่อเครือข่ายคอมพิวเตอร์ทั่วโลกเข้าด้วยกันผ่านชุดของโปรโตคอลที่เรียกว่า TCP/IP (Transmission Control Protocol/Internet Protocol) ข้อมูลจะถูกแบ่งออกเป็นแพ็กเก็ตเล็กๆ และส่งผ่านเครือข่ายจากคอมพิวเตอร์หนึ่งไปยังอีกเครื่องหนึ่งโดยใช้เราเตอร์และสวิตช์

## **หลักการทำงานพื้นฐาน:**

1. **IP Address:** ทุกอุปกรณ์ที่เชื่อมต่ออินเทอร์เน็ตจะมีหมายเลขประจำตัวที่เรียกว่า IP Address ซึ่งทำหน้าที่เหมือนกับที่อยู่บ้าน ช่วยให้คอมพิวเตอร์สามารถระบุและส่งข้อมูลถึงกันได้
2. **Domain Name System (DNS):** เนื่องจากการจำ IP Address เป็นเรื่องยาก DNS จึงทำหน้าที่แปลงชื่อโดเมนที่เราคุ้นเคย (เช่น [URL ที่ไม่ถูกต้องถูกนำออกแล้ว]) เป็น IP Address ที่คอมพิวเตอร์เข้าใจ
3. **TCP/IP:** โปรโตคอล TCP/IP เป็นชุดของกฎที่ควบคุมการสื่อสารข้อมูลบนอินเทอร์เน็ต TCP ทำหน้าที่แบ่งข้อมูลเป็นแพ็กเก็ตและตรวจสอบความถูกต้อง ขณะที่ IP ทำหน้าที่กำหนดเส้นทางการส่งแพ็กเก็ต
4. **Routers and Switches:** เราเตอร์ทำหน้าที่ส่งต่อแพ็กเก็ตข้อมูลระหว่างเครือข่ายต่างๆ ส่วนสวิตช์ทำหน้าที่ส่งต่อแพ็กเก็ตข้อมูลภายในเครือข่ายเดียวกัน

## **ภาพรวมการทำงาน:**

1. เมื่อคุณพิมพ์เว็บไซต์ลงในเบราว์เซอร์ คอมพิวเตอร์ของคุณจะส่งคำขอไปยัง DNS Server เพื่อค้นหา IP Address ของเว็บไซต์นั้น
2. เมื่อได้ IP Address แล้ว คอมพิวเตอร์ของคุณจะส่งคำขอไปยังเว็บเซิร์ฟเวอร์ที่เก็บข้อมูลของเว็บไซต์นั้น
3. เว็บเซิร์ฟเวอร์จะส่งข้อมูลกลับมาในรูปแบบของแพ็กเก็ตข้อมูล ซึ่งจะถูกส่งผ่านเครือข่ายโดยใช้เราเตอร์และสวิตช์
4. เมื่อแพ็กเก็ตข้อมูลถึงคอมพิวเตอร์ของคุณ เบราว์เซอร์จะนำแพ็กเก็ตเหล่านี้มารวมกันและแสดงผลเป็นหน้าเว็บที่คุณเห็น

## HTTPS

HTTPS (Hypertext Transfer Protocol Secure) คือโปรโตคอลที่ใช้ในการสื่อสารข้อมูลผ่านอินเทอร์เน็ตที่มีความปลอดภัย โดยเพิ่มชั้นของการเข้ารหัสข้อมูลลงบน HTTP ซึ่งเป็นโปรโตคอลพื้นฐานในการรับส่งข้อมูลบนเว็บ

## **HTTPS ทำงานอย่างไร:**

1. **SSL/TLS Handshake:** เมื่อคุณเข้าเว็บไซต์ที่ใช้ HTTPS เบราว์เซอร์ของคุณจะทำการ "จับมือ" กับเว็บเซิร์ฟเวอร์ผ่านกระบวนการที่เรียกว่า SSL/TLS Handshake เพื่อสร้างการเชื่อมต่อที่ปลอดภัย
    - เบราว์เซอร์จะตรวจสอบใบรับรอง SSL/TLS ของเว็บไซต์ เพื่อยืนยันว่าเว็บไซต์นั้นเป็นของจริงและเชื่อถือได้
    - เบราว์เซอร์และเว็บเซิร์ฟเวอร์จะตกลงกันเรื่องวิธีการเข้ารหัสข้อมูลที่จะใช้ในการสื่อสาร
2. **การเข้ารหัสข้อมูล:** ข้อมูลทั้งหมดที่ส่งระหว่างเบราว์เซอร์และเว็บเซิร์ฟเวอร์จะถูกเข้ารหัส ทำให้ผู้ที่แอบดักฟังข้อมูลไม่สามารถอ่านข้อมูลได้
    - การเข้ารหัสนี้ใช้กุญแจที่สร้างขึ้นระหว่าง SSL/TLS Handshake
3. **การรับส่งข้อมูลที่ปลอดภัย:** เมื่อการเชื่อมต่อที่ปลอดภัยถูกสร้างขึ้นแล้ว ข้อมูลทั้งหมดที่ส่งระหว่างเบราว์เซอร์และเว็บเซิร์ฟเวอร์จะถูกเข้ารหัสและถอดรหัสโดยอัตโนมัติ ทำให้มั่นใจได้ว่าข้อมูลของคุณปลอดภัยจากการถูกดักจับหรือแก้ไข

## **ประโยชน์ของการใช้ HTTPS:**

- **ความเป็นส่วนตัว:** ข้อมูลส่วนตัวของคุณ เช่น รหัสผ่าน ข้อมูลบัตรเครดิต หรือข้อมูลส่วนบุคคลอื่นๆ จะถูกเข้ารหัสและปลอดภัยจากการถูกขโมย
- **ความสมบูรณ์ของข้อมูล:** มั่นใจได้ว่าข้อมูลที่คุณได้รับนั้นไม่ถูกแก้ไขหรือดัดแปลงระหว่างการส่ง
- **ความน่าเชื่อถือ:** เว็บไซต์ที่ใช้ HTTPS จะแสดงสัญลักษณ์แม่กุญแจในแถบที่อยู่ ซึ่งบ่งบอกว่าเว็บไซต์นั้นมีความปลอดภัยและเชื่อถือได้

## Domain name

Domain Name หรือชื่อโดเมน คือชื่อที่ใช้แทนที่อยู่ IP Address (ตัวเลขที่ระบุตำแหน่งของเว็บไซต์ในอินเทอร์เน็ต) เพื่อให้ง่ายต่อการจดจำและใช้งาน เช่น "[URL ที่ไม่ถูกต้องถูกนำออกแล้ว]" หรือ "wikipediaorg”

## **Domain Name ทำงานอย่างไร:**

1. **การพิมพ์ชื่อโดเมน:** เมื่อคุณพิมพ์ชื่อโดเมนลงในเว็บเบราว์เซอร์ คอมพิวเตอร์ของคุณจะส่งคำร้องขอไปยัง DNS Server (Domain Name System Server)
2. **DNS Server ค้นหา IP Address:** DNS Server ทำหน้าที่เหมือนสมุดโทรศัพท์ของอินเทอร์เน็ต โดยจะค้นหา IP Address ที่ตรงกับชื่อโดเมนที่คุณพิมพ์
3. **ส่งต่อคำร้องขอไปยังเว็บเซิร์ฟเวอร์:** เมื่อ DNS Server พบ IP Address ที่ตรงกันแล้ว จะส่งต่อคำร้องขอของคุณไปยังเว็บเซิร์ฟเวอร์ที่เก็บข้อมูลของเว็บไซต์นั้นๆ
4. **เว็บเซิร์ฟเวอร์ส่งข้อมูลกลับ:** เว็บเซิร์ฟเวอร์จะตอบสนองต่อคำร้องขอของคุณโดยส่งข้อมูลของเว็บไซต์กลับมาให้คอมพิวเตอร์ของคุณ ซึ่งจะแสดงผลในเว็บเบราว์เซอร์

## **โครงสร้างของ Domain Name:**

Domain Name ประกอบด้วยส่วนต่างๆ ดังนี้:

- **Top-Level Domain (TLD):** ส่วนขวาสุดของชื่อโดเมน เช่น ".com" ".org" ".net" ".th" เป็นต้น
- **Second-Level Domain (SLD):** ส่วนที่อยู่ทางซ้ายของ TLD ซึ่งเป็นชื่อที่คุณเลือกเอง เช่น "google" ใน "[URL ที่ไม่ถูกต้องถูกนำออกแล้ว]"
- **Subdomain (ถ้ามี):** ส่วนที่อยู่ทางซ้ายของ SLD เช่น "www" หรือ "mail" ใน "[www.google.com](https://www.google.com/)" หรือ "mail.google.com"

## **ประโยชน์ของ Domain Name:**

- **ง่ายต่อการจดจำ:** ชื่อโดเมนที่สั้นและมีความหมายจะง่ายต่อการจดจำมากกว่า IP Address ที่เป็นตัวเลขยาวๆ
- **สร้างความน่าเชื่อถือ:** ชื่อโดเมนที่เหมาะสมจะช่วยสร้างความน่าเชื่อถือให้กับเว็บไซต์หรือธุรกิจของคุณ
- **ง่ายต่อการจัดการ:** คุณสามารถเปลี่ยน IP Address ของเว็บไซต์ได้โดยไม่ต้องเปลี่ยนชื่อโดเมน
